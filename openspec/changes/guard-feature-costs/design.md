# Design

每 scope 一个全局计数文档、每用户一个计数文档，固定 ID 不随日期无限增生。文档保存当前北京时间日窗口和分钟窗口的用量；事务内一次读取并检查两个文档后写入。拒绝旧窗口回滚，拒绝损坏计数和不合格配置。无数据库连接时拒绝额外功能，不影响旧打卡 API。

每用户文档 owner 为派生账户 ID，删除主账户时按 owner 清理；全局无身份字段。删除不能退还全局用量。删除与限流写入竞态在后续账号代际事务集成中重新检查；额度计数不含习惯、公开内容或原始身份。

入口必填每分钟/每日上限，整数有界。不把应用次数额度描述成货币硬预算：每次拒绝仍可能产生平台调用和少量计数查询费用，部署前必须配置平台限并发、最大实例/调用配额、账单告警并测试停服开关。固定窗口有边界突发特性，不适合证明每滑动分钟绝对上限。

本实例已拒绝的 global/user scope 暂缓存到对应窗口结束（最多 512 项）。跨实例总数仍以云事务为准，不因进程重启重置。
