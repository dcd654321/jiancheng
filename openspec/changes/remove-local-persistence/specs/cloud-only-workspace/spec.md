# Cloud-only Workspace

## Purpose

正式习惯数据只保存在云端；客户端运行内存可暂存当前已确认响应和进行中的请求，但不持久化数据到设备。

## ADDED Requirements

### Requirement: 云端唯一持久来源

客户端 SHALL 在启动时读取云端账户；不得使用或写入本机存储作为账户、习惯、打卡、设置或待同步操作的持久来源。

活动客户端 SHALL 不提供生成设备文件的 CSV/JSON 导出和旧版本机恢复入口；历史版本在设备上留下的键不得静默清除或重放。

#### Scenario: 清空本机缓存后打开
- **WHEN** 用户用同一微信账号重新打开且云端可用
- **THEN** 页面读取该账号云端状态，得到已确认的习惯与记录

#### Scenario: 启动时断网
- **WHEN** 云端不可访问
- **THEN** 页面显示不可用与重试，不显示旧缓存或可编辑空账户

### Requirement: 直写并确认

客户端 MUST 在云端返回匹配操作标识、账户、代际与版本的成功确认后，才把修改显示为已保存；未知结果不得报成功或悄悄形成离线队列。

#### Scenario: 打卡请求超时
- **WHEN** 请求可能到达云端但客户端未收到确认
- **THEN** 页面显示结果未确认，当前会话可用相同操作标识重试；重启后以云端读取结果为准

#### Scenario: 另一设备抢先修改
- **WHEN** 云端返回版本冲突
- **THEN** 不覆盖云端或乐观显示本次修改，提示刷新后重新操作

### Requirement: 云端删除可恢复

删除清理在云端进入待完成状态后，系统 MUST 能在客户端重启、没有本机请求记录的情况下继续同一次删除，不允许旧数据复活。

#### Scenario: 删除后客户端退出
- **WHEN** 云端已记录删除意图但清理尚未完成
- **THEN** 下次进入可通过云端状态继续清理，并在确认前不显示可编辑的新空账户
