# Proposal

## Why

当前客户端即使已配置云环境，仍要求用户点击“同意并开始使用”才读取正式账户；这使云端作为默认数据源的产品行为不一致，也让首次使用多走一步。小程序本机存储仅用作已确认快照和待同步队列，不能作为唯一持久来源。

## What Changes

- 已配置云环境时，启动自动读取当前微信身份对应的云端账户，不再设置应用自定义的“同意云端存储”关卡。
- 首次读取失败时不显示可编辑的空账户，提供重试；已有确认缓存继续按原有离线与冲突规则处理。
- 清理页面上的旧关卡文案。AI 向第三方发送内容的单次同意、订阅消息授权、隐私说明与数据删除仍独立保留。
- 不修改云函数、集合、权限、账户身份规则或正式环境配置。

## Capabilities

### New Capabilities

- `default-cloud-workspace`: 已配置环境中的默认云端启动与失败保护。

### Modified Capabilities

无。

## Impact

- 客户端会话启动、同步状态页和各入口的加载提示；相关自动化测试。
- 不改变云端数据格式；旧本机“同意”标记不再决定是否读取，旧账户绑定和队列仍按环境命名空间隔离。
