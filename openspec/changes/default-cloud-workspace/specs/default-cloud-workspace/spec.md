# Default Cloud Workspace

## Purpose

云端账户是本小程序习惯与打卡的默认正式数据源；本机存储只保存快照和待同步操作。

## ADDED Requirements

### Requirement: 自动读取云端账户

已配置云环境时，客户端 SHALL 在启动时自动按可信微信身份读取云端账户，不得要求用户先点击应用自定义的云存储同意按钮。

#### Scenario: 首次打开
- **WHEN** 用户首次打开已配置云环境的小程序且没有本机云同意标记
- **THEN** 客户端自动请求云端账户，成功后展示云端习惯或新账户空状态

### Requirement: 读取失败保护

首次读取失败时，客户端 MUST 保持不可编辑状态并展示重试；不得把失败解释为无习惯账户。已有快照和待同步操作 SHALL 遵守现有离线、冲突及身份隔离规则。

#### Scenario: 首次离线
- **WHEN** 没有可用账户快照且云请求失败
- **THEN** 页面显示读取失败和重试入口，不允许创建或打卡

### Requirement: 单独授权保留

去除云存储启动关卡 MUST NOT 删除向第三方 AI 发送输入前的单次确认、微信订阅消息授权以及数据隐私说明和清除入口。

#### Scenario: 请求 AI 细化建议
- **WHEN** 用户未同意发送本次输入到第三方 AI
- **THEN** 请求不发送，基础规则建议仍可用
