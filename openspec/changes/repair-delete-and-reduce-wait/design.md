# Design

## Context

见提案的源码观察。本轮先核对部署版本，不能以本地协议支持推断线上已支持。管理页为非 tab 页面 `pages/manage/index`，现有删除使用 `switchTab` 到今日。共享云每个 transport 闭包独立创建 Cloud；已有账户只读事务产生 start/get/commit 三次 SDK 底层请求。客户端回执先在 validateReceipt 验证，随后 acceptSnapshot 再验一次。

## Goals / Non-Goals

Goals：修正删除返回、减少不必要初始化和读事务，压缩提示占屏时间，以请求数和真实 SDK 序列验证改变。

Non-Goals：不做乐观移除/完成，不持久化连接或数据，不压缩/改造账户数据协议，不自动升级运行环境或付费保温，不承诺未经测量的线上毫秒数。

## Decisions

1. 导航查找页面栈中的管理页并 navigateBack；不存在时 redirectTo。导航失败显示管理页出口，所有回调保持原 context/showVersion 隔离。修改既有删除提案与文档中的“今日”返回描述，数据删除契约不变。
2. repository 增加严格的只读账户读取；handler 认证和请求校验后，正常已有账户直接校验并返回。缺失或 cleanupPending 时继续旧事务流程，读取失败不降级为空账户。并发变化仍由写入 expectedRevision 校验；每次读取都访问云数据库。
3. 模块内 WeakMap 按 wx.cloud API 对象分组，按资源方 AppID/环境标识保存初始化 Promise。构造 transport 时不联网；失败只移除同一失败条目，后续可重试。目标白名单在复用前验证。连接对象不包含本项目额外账户缓存；账户数据仍在各会话内隔离。
4. acceptSnapshot 提取已验证快照接收函数；pull 和冲突快照仍校验，成功 write 路径在 validateReceipt 校验后直接接收，不减少任何校验规则。前台窗口使用确认完成时间，避免慢响应后立即再读。
5. 保留事务完整性；减少 server mutate 中与纯 reducer 重复的深拷贝，保留独立 receipts 数组，失败不能原地污染 saved。完成只保留 1200 ms 原生提示，移除底部反馈及其定时器；列表保持用户选择的展开状态，紧凑行提供详情和撤销。
6. 详情、管理清单和进度习惯摘要展示最新已确认计划状态。详情动作直接命名“暂停”“恢复”“归档”“取消归档”，生效时间放在辅助说明中，移除通用修改撤销及预告区块。今天进行中、明日暂停时，“恢复”在目标等字段一致时通过 cancelFuture 恢复该状态，另有目标修改时只用 status active 保留目标修改。尚未生效归档的“取消归档”恢复当前状态，原来暂停的习惯仍保持暂停；已生效归档通过 status active 设置明日进行中。今天任务及历史统计继续使用日期版本，状态展示只在合法云确认后更新。
7. ui.mutate 绑定当前 context/showVersion，在同次可见访问写入期间不重复进行订阅数据投影，合法成功统一刷新一次；失败先接收可信新快照再显示错误。新访问和其他页面订阅不受原写入抑制。首次/回归完成短后缀改为统一“打卡成功”，不为判断首次额外拷贝全部记录。
8. 动作文案统一“打卡”，包括按钮、成功/等待/撤销、统计、说明与外观预览。保留数据库 status 值与协议动作，备注保存、计划保存仍明确其各自操作。

## Risks / Trade-offs

- 只读期间另一设备变化：返回读取时的合法快照，后续写入仍严格 CAS；不增加缓存有效期。
- 共享初始化串目标：使用资源方、环境及 API 对象完整键，覆盖隔离与失败重试测试。
- 草稿与导航迟到：沿用回执和页面访问隔离，补充管理页返回与导航失败用例。
- 真正耗时可能来自网络/云冷启动：本地只证明请求数、计算和交互时长改变，真实响应需单独验收。

## Migration Plan

用户本轮要求修复后在 dev 实施，执行全部本地验证与生成一致性检查。部署需另行明确目标环境与 API 产物，不改环境变量/数据库规则/其他应用。回退本轮源码片段并重新生成即可恢复事务只读和原提示；代码回退无法恢复已删除数据。
