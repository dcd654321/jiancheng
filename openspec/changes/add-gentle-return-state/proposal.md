# Proposal

## Why

今日页只显示当天任务。用户连续几次没有记录后回来，看不到一个基于真实计划的轻量入口，容易把短暂中断理解为“前功尽弃”。现有计划版本和打卡记录已足够推导这一状态，无需新增云端数据。

## What Changes

- 仅当今天有未完成任务，且该习惯最近至少两个已结束的计划日连续未记录时，显示温和的回归提示；休息日跳过，未开始、暂停、归档及已有完成记录中断判断。
- 给出今天按原目标继续、或手动选择更小目标两个入口。目标为 1 时不提供无效的小目标；点击小目标仍需另行确认实际完成。
- 待同步、冲突或云端状态不确定时优先显示同步提示，不以回归文案否定本机已记录的行动。完成后回归提示消失，反馈不阻断操作。
- 增加跨日、计划变更、休息日、暂停/恢复、离线与冲突的测试和验证记录。

非目标：不补签、不清零或改写历史、不自动完成任务、不新增权威字段、云函数、定时任务、提醒、积分或 AI；不因此开启正式环境或合并 `main`。

## Capabilities

### New Capabilities

- `gentle-return`: 根据现有计划与记录判断何时显示回归入口及如何选择今天的目标。

### Modified Capabilities

无已归档基础规范需修改。

## Impact

影响客户端今日页、一个纯推导服务、样式和测试。继续复用已有 `taskAt`、历史计划版本、今日简化/恢复/完成操作及同步状态；不改变云端协议、集合或数据迁移。P0-A 的原生与真机验收仍独立待办。
