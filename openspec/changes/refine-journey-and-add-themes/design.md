# Design

## Context

动机见[proposal](proposal.md)。运行证据在[本轮证据索引](../../../docs/audits/2026-09-30-journey-review/EVIDENCE.md)；逐页、token、合同细节在[AI执行规格](../../../docs/AI-OPTIMIZATION-HANDOFF-20260930.md)，验证步骤在[验收清单](../../../docs/AI-OPTIMIZATION-ACCEPTANCE-20260930.md)。这些文件共同组成实施输入，不能只按生成图片重写页面。

当前基线b3355eb已实现双主题、主题云协议、紧凑确认及共享恢复。2026-10-01复核记录见[UI复核](../../../docs/UI-INTERACTION-REVIEW-20261001.md)：两订阅覆盖预览、旧冻结请求残留、写入与撤销反馈不完整。当前模板为30/10（整理10/3）；助手页面已删除；完成立即移入已完成分组并自动展开。

根AGENTS要求云端权威数据、无本机账户持久快照/离线队列；本轮修客户端、相关服务端逻辑、生成副本、测试与文档，真实云端部署另行授权。

## Goals / Non-Goals

**Goals:**

- 最大限度复用现有领域命令、页面路由与会话恢复，修改用户可见信息及状态组织。
- 共享结构和语义token实现两个主题，云偏好可独立启用、失效和回滚。
- 每个需求对应可复现验收，不把静态稿、注入渲染、自动测试及云端/真机证据混为一类。

**Non-Goals:**

- 不新增离线队列、计时、习惯名额、统计算法、自动调整目标或新的认证路径。
- 不更换导航架构、不复制两套业务页面、不新增设置中间页。
- 本轮实施本项目逻辑修复；不写真实云端、部署、迁移、提交或合并。

## Decisions

### D1：在共享生命周期内收敛恢复

提取today现有读取重试到共享UI层，页面消费一致loading/unavailable/retrying状态。复用withLifecycle的可见性、版本和日期机制；防重复请求，检查context与页面是否仍有效。公开分享页用原公开读取器，不要求私有账户就绪。

未知写入复用现有session.retry/recoverConnection；禁止重新dispatch产生新的operationId。把“先核对”解释为同请求幂等恢复，无需另建operation查询接口。原网络恢复防抖与单次触发保持。

替代方案：每页各写重试容易产生生命周期分叉；新增全局轮询增加请求并不能解决幂等问题，均不采用。对应UX-01 / A01–A06。

### D2：edit内分两种呈现，不拆创建协议

模板和有效草稿走紧凑确认，自定义/编辑走完整表单；字段和验证复用plan-form及domain。频率默认收起但摘要可见，开始日始终可见；键盘关闭时固定提交区，打开时回到内容流，预留真实安全区。

保留_id、baseRevision、startDate及一次性草稿上下文。主题/恢复只重绘，不重新onLoad或构造创建命令。容量冲突不能自动切日期。

替代方案：新增确认页会使字段副本、返回修改及草稿所有权更复杂；删除频率设置损失控制，因此不采用。对应UX-03 / A11–A17。

### D3：即时归组与可见纠错反馈

完成确认后立即移入已完成并展开。底部轻量反馈仅持有最新确认项的ID，内容从权威完成状态派生，显示名称/实际目标及撤销，另有定位全部已完成入口。每次确认后显示5秒；连续完成重置计时，普通刷新不延长。到期、撤销最新项、onHide、onUnload、context或日期变化清空ID与定时器，旧项不重新出现。长期撤销入口保留在已完成分组，历史及统计不变，不自动滚动打断下一项。

共享串行锁配套writeBusy、recordingId与操作文案；所有相关写按钮等待时禁用，当前项显示正在记录/正在撤销。新操作开始清除上次拒绝文案。异步写入、表单保存、数据恢复、功能预览和确认弹窗捕获context及本次onShow版本，回调仅在同一可见访问处理提示、导航、页面状态或后续确认提交；操作锁最终释放。已发事务仍可确认，返回后由权威数据读取展示。忙时撤销仍保留当天2，不改长期5。

主卡只放两档记录，单独调小在详情明确“只调整今天目标（不记录）”；关闭quickMinimum仍可通过详情调整再记录。对应R3/R4/R5与A18–A26。

### D4：单一组件结构、双套语义颜色

使用page/surface/ink/secondary/primary/busy/soft/border/error等token，所有页面与自绘状态一致消费。默认mist，paper只换颜色；系统无衬线字、44px触区与48px推荐按钮。忙时色限小标签，日常记录用描边，提交才用低饱和实心。

基础库支持检查在实施时记录：若WXSS变量在目标渲染链路不可靠，从同一token源生成主题作用域样式，业务WXML不复制。原生导航/Tab使用官方能力并验证图标素材；系统键盘/授权弹窗不纳入换肤承诺。

替代方案：两个独立UI方向会改变布局和肌肉记忆；整体透明度降低会损害对比度，因此不采用。对应UX-02/TH-01 / A07–A10、A27–A30。

### D5：同函数、同偏好集合，独立主题动作与开关

新增appearance配置/客户端与主题页面，客户端默认关闭。云端在features入口识别白名单getAppearance/setAppearance，使用独立HABIT_APPEARANCE_ENABLED；身份、清理、限流、平台来源/AppID条件仍必须满足。旧features/reminder动作继续按原开关限制，不被新开关放开。

新增theme可选字段，合法枚举mist/paper；缺失读取mist、不写库、不迁移，非法值报告PREFERENCES_CORRUPT。主题成功投影仅revision/theme（写入可含replayed），不返回整份偏好。共享revision和preferenceReceipts，先幂等核验再版本比较；主题写只改允许字段，原偏好写保留theme。重放返回当前视图，与现有偏好幂等语义一致。

替代方案：打开features总开关风险不必要；扩展原patch强耦合门控；独立新云函数/集合增加资源管理，因此选择原函数内独立动作。对应TH-02 / A31–A42。

### D6：账户会话级保存协调、页面级预览

外观页通过共享主题通知钩子统一syncView，不允许通用已保存theme覆盖本页预览。固定保存栏含状态和安全区，内容预留栏高。页面只持previewTheme；appearance客户端持当前context、已确认theme/revision、在途读取和最多一个冻结保存请求。保存成功校验context后广播主题，不重建页面。离页只取消预览；已发事务仍由协调器接收回执，未知结果可重入核对。

网络或服务结果不明保留冻结payload，只允许原ID重放；单纯读取颜色不能证明旧请求已经结束。明确冲突先读云端，保留预览，用户再次确认才新建操作。上下文/epoch/workspace generation变化清理内存、旧冻结及读取句柄并丢弃旧回包；同上下文的未知请求仍须原样核对。协调器订阅可信会话，view也核对当前key。每次异步任务捕获key及代次，旧catch/finally不能清除新请求。客户端保存准备与发送去重。冷启动不恢复本机请求，仅重新读当前云值。

外观读取不加入阻塞核心启动的dataReady链；默认浅底先可用，偏好读取去重，不定时轮询。无合法revision/离线/主会话pending或conflict时禁止主题保存。

替代方案：本机持久化能减少闪烁但违反项目数据约束；保存前全局乐观换肤会让失败像已成功；关闭页面即“取消事务”与云端事实不符，均不采用。对应TH-02 / A27–A29、A34–A38。

### D7：辅助说明减量，算法不扩展

删除助手页面和入口，保留已关闭云AI及内部规则模块。回归提示不复制任务动作，gentle-return条件保持。progress-advice只解释真实统计，分享直达不启用关闭能力。表单错误同时呈现具体恢复文字与2px错误边界，修正即清除，提交定位首错且保留其他值。

### D8：任务优先的信息层级

按[产品体验设计](../../../docs/PRODUCT-EXPERIENCE-DESIGN-20261001.md)落地已有能力的呈现优化。今日用一行“已记done/total、待做N项”替代大摘要和进度条；忙时次数仍可见，回归句去掉独立色块，保留原判定与动作。首次空态说明模板可修改，确认页明确两档只是可调目标，保留30/10与10/3默认和用户既有计划。记录按钮改为“按忙时N单位记下”，保留完整数值、进行中状态和读屏语义。

进度继续使用domain.summary、原始日期范围和progress-advice，顶卡先显示记录次数与两档次数；已有stats.habits列表前置，默认最多展示3项，其余复用showHabits展开。每个入口仍去相同详情，单项次数与总统计取同一周期；记录率/安排次数移到逐日明细之后。不产生排序评分、新建议规则、额外云读取或目标自动变更。详情“修改明日计划”仅明确既有次日生效规则。新一轮任务与证据列第9组；先前未覆盖的D/C/U不因本轮修改勾选。

### D9：逻辑复核的状态与持久化边界

共享读取的异常须结束加载并提供恢复，缓存回调异常也走相同出口。模板/自定义表单在第一次可信数据读取后绑定账户；已绑定表单遇到账户变化必须清空私有输入并要求重新打开，不自动改绑。创建结果经云端重新确认后，若本表单ID已存在，输入和生效日一致可返回今日且不再写；修改过输入则保留并解释应到详情编辑，不把领域幂等无操作显示成修改成功。

首次创建引导使用真实firstDate，仅确为次日时写明天，其他未来日写日期；跨日或context变化清理旧引导。主题客户端与全局控制器在同一账户接受的revision不能倒退；旧读取不得覆盖更高版本保存，强制重读仍保留已确认最高版本。置顶偏好缓存同样拒绝较低revision，迟到的旧保存不能覆盖较新确认。外观保存及同步错误按发起访问版本隔离，仍由会话协调器接收已发事务。记录请求跨业务日期确认时只刷新当前权威内容，不弹昨天的完成或失败提示。

云仓库在调用事务operation前序列化原文档，与结果比较，避免原地修改使前后引用相同而漏写cleanupPending/cleanupSourceEpoch清除。提醒鉴权与收件人均复用平台受信callerIdentity；共享调用使用FROM_APPID/FROM_OPENID，不读取事件身份、不新增认证路径或开放功能。以安装的CloudBase SDK本地合同证明清理完成标记实际落入拦截数据库、后续pull不重复清理；提醒夹具验证加密接收人属于调用方。来源修改后统一build:cloud；真实共享环境发送和删除验收单独记录。

## Risks / Trade-offs

- [样式变量/原生API支持未核验] → 记录目标基础库、微信工具与真机验证；不支持时保持中性可读原生区域，token采用单源生成作用域样式。
- [主题读取延迟出现一次配色变化] → 默认浅底、无动画、读取去重；不以本机账户缓存或阻塞核心页面换取无闪烁。
- [共享偏好revision导致跨设备冲突] → 明确冲突提示、读最新再由用户确认；不自动覆盖。
- [离页后的写入仍可能成功] → 保存协调器和明确待核对状态；不承诺取消已发事务。
- [完成反馈常驻或旧项重新出现] → 最新项5秒展示、清除ID和定时器、统计只用领域状态，测试连续完成、撤销、午夜及context变化。
- [本地模拟被误认为云已通过] → L/W/D/C/U逐层报告，所有实施任务初始未勾选；受阻就记录BLOCKED。
- [共享生成副本扩散] → 从server源修改并build，核对各副本来源，部署目标需单独审查授权。

## Migration Plan

1. 当前获用户授权执行R1–R7修复；保留主体实施及后续主题开关决策，本轮不改变能力配置。
2. 不批量迁移偏好：theme缺省mist，读路径无写，用户保存才新增字段；不碰其他小程序资源或共用认证。
3. 运行构建及常规/规范检查，确认SDK锁定依赖和合同测试实际执行；微信工具、真机、双账户另附证据。
4. 云端集成前列清环境、函数、代码/配置差异、开关、安全前提和恢复边界，取得适用授权。共享模块生成差异不等于允许部署全部函数。
5. 回滚先关闭主题入口与独立能力，核心默认外观继续可用；保留theme和历史，不清空账户。回退旧服务前检查字段与收据兼容；不能确认时保留新版服务并关闭新动作。
6. 用户测试确认后才安排独立发布/合并授权。规范文件齐全不代表实施完成、部署完成或生产就绪。
