# Proposal

## Why

计划助手目前只有本机规则和关闭的云调用占位。用户希望工具为主、AI 增强且成本可控，需要补真实适配、重复计费防护和安全边界。

## What Changes

- 新增默认关闭的 `jiancheng_daka_plan` 云函数，受信身份、账户代际与明确同意门控。
- 第一种可选服务端适配为 DeepSeek JSON 接口；模型和价格预算需部署者确认，本批不填密钥、不实际调用、不默认采购供应商。
- AI 仅在已审核四方向动作目录中选择动作/说明和整数目标；不直接展示任意模型文本。前端仍注明 AI 建议、非保证，需预览和确认采用。
- 每用户日次数、全局日/月最大预留成本、请求幂等和失败不重试；同账户单个在途请求。
- 客户端走共享云实例、只发本次方向/时间选择，规则建议永久无需模型。

## Capabilities

### New Capabilities

- `budgeted-ai-plan`: 受预算约束的结构化计划增强。

### Modified Capabilities

无。

## Impact

新增私有 `jiancheng_daka_ai_requests` 与 `jiancheng_daka_ai_budget` 集合，主删除联动。请求结果目录文本为本地审核内容，AI 不自由写文案；供应商任意文本不落库、不返回前端。配置与真实计费/跨用户/真机另验，现有规则路径不变。
