# Design

## Context

依据 FEATURE-DESIGN-20260924.md 与 FEATURE-DATABASE-20260924.md。当前运行仍为旧测试云；正式共享身份待验证，因此旁路入口不能启用。

## Decisions

私有入口复用严格可信身份要求，只处理本人既有主账户。每个私有请求携带期望 epoch，服务端与权威账户比较；旧页面不能在删除后的新账户创建内容。缺账户、删除清理中、缺字段、权限或存储异常全部拒绝，不补建假空账户。

为使数量限制与幂等在并发下可靠，偏好文档增加仅服务端可见的 `shareIndex`（最多 200 个 ID/日期/状态）、`dailyCreates`（当日最多 10 个请求指纹）、`preferenceReceipts`（64 个近期 CAS 回执）。同 owner 的操作通过同一偏好文档事务写入串行化；分享内容仍单独存分享集合。只用事务文档点读写，不假定支持事务范围查询。列表在事务中读索引对应的一页文档（最多 20 条），返回游标，不允许客户端指定 owner。

创建输入含 requestDate（服务端北京时间当天）、32 字节安全随机 requestId、epoch。分享 ID = SHA256(owner:epoch:requestId)，同操作内容指纹一致才可重放。创建日期限制与当日回执共同阻止删除分享后同请求重新公开；超出当日的新重试不自动重新发布。每人 50 活跃、200 历史、每天 10 新建上限。撤回不删除本人历史；删除移除内容与索引，但保留当日最小幂等回执。偏好 revision 只在用户偏好修改时递增，分享索引写入不产生无关设置冲突。

预览同时由服务端 `crypto.randomBytes(32)` 生成 requestId，客户端保留原预览请求号用于确认及重试，不以 Math.random 生成公开链接种子。本人详情增加 `getMyShare(shareId)` 点读接口，与列表相同的 owner/epoch 门禁，供本人阅读已过期或撤回的快照；公开入口仍拒绝这些内容。

预览由服务端读取当前账户生成，创建带上已预览账户 revision；源数据变化时要求重新预览，不发布未看过的内容。允许类型为固定邀请、预设类别轻计划、已结束七个自然日总数。类别、单位、文案严格白名单，不接收用户自填标题/备注/图片；公开响应重新组装并校验，绝不直接返回数据库整文档。

公开读取每次检查分享状态/90 天期限以及主账户 epoch 和 cleanupPending。不可用结果统一，不返回 owner、sourceRevision、requestId、备注或身份。真实未登录朋友圈读取能力仍需实测，未验证前不开启。

删除账户采用两个阶段：事务更换 epoch 并标记 cleanupPending；批量删除本应用旁路集合；清理成功后事务确认。任何清理失败均返回 DELETE_PENDING，不给客户端空快照；重放同 purge operationId 继续清理。清理期间 pull、mutate 和新功能请求拒绝，避免旧数据复活。仅开启旁路能力时要求清理适配器，旧测试兼容不改变。

## Rollout and Rollback

本地实现与 mock/SDK 合同验证后提交 dev。先准备拒绝客户端直读写的集合、权限与配套后端删除功能，再经共享身份及双账户验证后启用客户端。回退前先关闭公开与创建能力；旁路存在后不能回退到不会清理这些数据的旧 purge。需保留清理适配器或先完成授权的数据处理。无自动数据迁移。
