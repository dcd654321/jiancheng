# Design

## Context

基线 dev/c4bd827，origin/dev 已同步；仅未跟踪 .claude/ 为用户已有文件。当前 W 截图01–03显示今日、我的与进度双主题结构；助手不可达。core/plan-assistant、services/plan-assistant 和 edit 的一次性 draft 交接可复用。旧 config 的本机缓存背景与当前 AGENTS 冲突，以云端唯一持久来源执行。

## Goals / Non-Goals

Goals：完整可发现、可恢复、可确认的 AI 新习惯路径。
Non-Goals：修改已有习惯、增加自由模型文案、调整认证或自动部署；沿用 proposal 的环境范围。

## Decisions

- 保留双主题与现有组件；方向2列、时长快捷项、安排折叠、AI主按钮、基础方案次按钮，避免引入新的设计系统。
- 本次同意绑定当前输入，任何安排变更清除同意与建议；只发送原合同字段。基础方案允许在模型等待期间使用，递增页面访问版本使迟到 AI 安静丢弃。
- 服务端独立产品开关默认开放且支持 false 回退，其余核验开关仍严格 true，预算/供应商无缺省值。客户端 enabled 表示允许功能入口，不能作为模型或云环境已就绪证据。
- 服务 status 暴露阻断原因及在途状态；页面用本地请求版本、showVersion、context、日期四重校验。错误字段与读取状态分开，避免云刷新擦除 AI 错误；等待轮询只读取内存状态。
- 成功结果在有界会话请求表复用；网络失败/超时核对原 operationId/date。草稿只保存在内存，确认页遵守现有容量、离线、版本和保存规则。

## Risks / Trade-offs

- [云端仍未配置或部署] → 用户可用基础方案；交付明确模型未实调，不推定密钥/预算。
- [在途模型不能取消] → 页面仅忽略结果；服务锁和服务端预留继续限制重复请求。
- [模拟器无法证明真机] → W/F分开，补自动合同与原生编译；D/C/U不计通过。
