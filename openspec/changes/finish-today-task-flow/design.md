# Design

## Context

当前每日任务最多五项，时间与 ID 稳定排序，完成项折叠。原目标或小目标完成通过既有队列处理。无需新增持久记录。

## Decisions

临时撤销只保留最近一次本页完成，记录当时列表次序、账户上下文和日期，6 秒后消失。它只是展示，不新增定时业务写入；点击继续调用 `undo`。成功写入本地待同步队列不等于云端确认，状态文案沿用同步状态。隐藏、卸载、跨日、上下文变化或任务被撤销后立即清理，不显示另一个账户信息。过期按钮不得操作新的日期。

通过纯展示模块计算明日任务及创建容量。容量计算覆盖今日、明日与未来版本的变更点，与领域最大五项规则相同；今天满且明天有空位时默认明天。最终保存仍走领域和服务端校验，不能用入口提示代替业务校验。

原有第一条引导、回归提示和已完成折叠保留；明日摘要最多展示三项，更多显示数量并提供管理入口。临时撤销用普通文档流，不覆盖其他控件。

## Verification and Rollback

自动测试覆盖 0/1/3/5 项、误触撤销、失败、跨日、隐藏、账户切换、未来暂停和容量竞争。原生编译和模拟器检查单列，真机仍待验收。独立提交到 dev；回滚对应提交即可，无数据库迁移。
