# Spec Delta

## ADDED Requirements

### Requirement: 完成后的原位撤销

系统 SHALL 在今日页最近一次打卡成功后，在原任务位置显示 6 秒撤销入口，并继续保留已完成列表的撤销。系统 SHALL 不在保存失败、跨日、账户变化或页面离开后保留该临时入口。

#### Scenario: 多项中误点一项

- **WHEN** 用户完成中间一项并在临时入口点击撤销
- **THEN** 仅恢复这项为待做，其他记录与顺序不变

#### Scenario: 过期页面

- **WHEN** 撤销条过期或页面隐藏后收到旧点击
- **THEN** 不写入过期记录，不把操作转到今天的其他记录

### Requirement: 明日安排

系统 SHALL 在今日全部完成或今天休息时，根据明日有效版本展示明日安排，不把计划时间表述为通知。

#### Scenario: 计划明天暂停

- **WHEN** 明日生效的状态为暂停
- **THEN** 明日摘要不包含该项，今日历史不变

### Requirement: 满额创建入口

系统 SHALL 按今日、明日及已存在的未来版本检查最多五项活动习惯，满额时提示管理；仅明天有容量时允许从明天创建。

#### Scenario: 今天五项且明天一项暂停

- **WHEN** 用户点击添加
- **THEN** 表单预选明天，保存仍执行领域容量校验

#### Scenario: 今天明天都已满

- **WHEN** 用户点击添加
- **THEN** 提示上限并可进入管理，不打开不能保存的新建表单
