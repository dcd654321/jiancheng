# Spec Delta

## ADDED Requirements

### Requirement: 前台使用与会话

系统 SHALL 在每次进入前台时创建会话，并在有效账户上下文中发送启动、每 60 秒累计前台毫秒和离开前台时的累计时长。累计时长从监控启动确认开始，后台时间和未绑定账户的加载时间 MUST 不计入时长；账户或代际改变 MUST 丢弃旧上下文的上报与重试。上报 SHALL 最多在内存中重试一次且不阻塞业务。

#### Scenario: 进入后台后重新打开
- **WHEN** 用户离开前台后再次打开小程序
- **THEN** 上一次会话停止计时并发送末次时长，新会话独立开始，后台停留时间不累加

#### Scenario: 上报失败后账户变化
- **WHEN** 上报失败等待重试时账户代际改变
- **THEN** 系统丢弃旧上报，不将旧会话写入新账户

### Requirement: 运行信号脱敏

系统 SHALL 通过现有共享云连接上报 app_start、固定代码的运行错误、未处理拒绝和业务云函数耗时。事件 MUST 仅包含路由、函数名、固定 code、毫秒、会话和运行版本等白名单数据；MUST 不包含原始错误、习惯标题、备注或客户端身份字段。监控请求 MUST 不触发自身性能监控。

#### Scenario: 异常包含私人文本
- **WHEN** 运行错误或未处理拒绝包含私人信息
- **THEN** 上报仅包含固定错误类型代码与白名单元数据，不发送该私人文本

### Requirement: 云端确认的业务转化

系统 MUST 仅在主事务成功提交后，根据有效前后状态产生 habit_created 或 checkin_completed。事件 MUST 使用可信调用方身份和服务端时间，按账户代际、操作标识与事件类型幂等。重放、无变化、失败和删除待处理 MUST 不产生事件；运营事件写入失败 MUST 不将成功业务改为失败。

运营写入等待 MUST 最多 500 毫秒，超时只记录固定码，迟到拒绝 MUST 被处理。客户端生命周期的同步或异步采集异常 MUST 不阻断账户读取、写入和前后台清理。业务 snapshot SHALL 返回 capabilities.monitorSessionMetadata=true；新客户端 MUST 只在可信 snapshot 显式声明该能力时加入 sessionId，旧云函数缺少能力声明时保持原业务信封。

#### Scenario: 打卡结果未知后重试
- **WHEN** 已提交打卡由同一 operationId 重放
- **THEN** 返回原有业务确认，不再新增完成事件

#### Scenario: 监控写入不可用
- **WHEN** 主事务已成功，监控集合写入失败
- **THEN** 业务仍返回成功，仅记录固定失败代码，用户习惯和打卡保持已确认状态

### Requirement: 个人遥测删除与旧请求屏障

系统 MUST 将本应用本账户的用户、每日使用、会话和事件遥测纳入持久删除清理链。全部清理完成前 MUST 返回 DELETE_PENDING，并支持原请求或后续 pull 继续清理。所有客户端遥测及云端业务事件 MUST 冻结已确认账户 epoch，在监控写入事务中核验当前 epoch 与 cleanupPending；旧代际或删除中的请求 MUST 不恢复已清除个人记录。

业务事件与每批遥测删除 MUST 在读取全部账户和目标文档后递增同一主账户的顶层 _monitorFence，再执行事件写入或删除。该内部计数 MUST 不改变业务 payload、revision 或客户端返回状态，业务账户保存 MUST 保留既有计数。并发账户写入引发事务冲突后的重试 MUST 重新核验代际与清理状态。SDK 明确返回集合不存在（-502005）时 SHALL 跳过该空集合；权限、网络及未知错误 MUST 继续 DELETE_PENDING，不能假称已清理。

#### Scenario: 清理失败后重新打开
- **WHEN** 个人数据清理已换代际但监控记录删除失败，用户重新打开小程序
- **THEN** 后续 pull 继续相同个人范围的清理，全部成功后才返回空账户的成功确认，其他应用和其他用户保留

#### Scenario: 删除后旧遥测或业务事件才到达
- **WHEN** 删除前已发出的运营事件在账户 epoch 改变后尝试写入
- **THEN** 监控事务拒绝旧代际，不新建或恢复用户、会话、每日使用或事件记录

#### Scenario: 旧事务读取后发生账户删除或新代际写入
- **WHEN** 旧业务事件或旧清理事务读取账户快照后，另一事务换代际或完成清理并开始新代际使用
- **THEN** 对同一账户的栅栏写入形成写冲突，重试回读账户并拒绝旧事件或退出旧清理，新代际记录保留
