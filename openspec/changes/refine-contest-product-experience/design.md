# Design

## Context

参见proposal及docs/designs/2026-10-07-contest-review/design-spec.md。2026-10-09当前源码以云端为账户唯一持久来源，模型集成与小目标助手均已移除，公开分享关闭。应用直接进入今日；无打卡项时居中显示“添加习惯”，忙时目标输入框默认展示。早期设计与截图保留历史状态，当前行为以本变更最新要求及源码为准。

2026-10-10用户要求调长四个模板的默认时长，给准备与进入状态留出时间。以下模板决策替代早期阅读5/1、步行10/3、复习5/2、整理3/1分钟要求；旧截图和验收记录仍反映当时状态，本次实施与验证另行记录。

## Goals / Non-Goals

Goals：减少首次决策负担；确保记录文案与事实一致；返回后可继续输入；保持账户与异步上下文隔离；落实设计规格中的本地体验。

Non-Goals：新增持久草稿、离线提交、改变记录领域数据结构、自动改历史或迁移现有目标、解除云权限、开启公开分享、真实账户写入、部署、发布。

## Decisions

1. 一个共享模板表提供阅读30/10、步行30/10、复习30/10、整理15/5分钟平时/忙时目标，给准备与实际执行留出时间。今日模板卡、模板创建确认页与外观预览均读取此表，仅影响未来从模板创建的习惯。已有习惯、历史记录和未提交的用户输入不修改；自定义表单与公开轻计划沿用原有输入及合同，用户仍可在确认页修改目标。
2. 不增加记录来源字段。既有直接忙时记录与先调小后记录的快照相同，因此以“本次记录X / 平时目标Y”描述结果，不能推断操作历史。
3. 会话草稿服务只使用内存Map；key包含受信账户context、业务日及新建入口/习惯id，最多8份。存输入与基础revision，跨账户/日期清除；旧异步回执不清除新草稿。明确本次打开保留、退出丢失。恢复旧revision仍由云端冲突拒绝。
4. 移除小目标助手的四个页面文件、规则领域与会话服务、注册路由、应用装配、今日与我的入口及共享云客户端 plan 调用白名单。编辑页拒绝旧 `draft` 参数，显示“该入口已停用，请返回今日添加习惯”，保存不得创建；`sharedDraft` 继续沿用公开轻计划的校验、账户隔离与可编辑确认。普通表单、四模板及其草稿恢复继续保留。
5. 公开内容先读不依赖私有账户。接收者点击采用后准备账户；异常保留公开内容并允许重新读取。仍在可编辑确认页显式创建，不自动写入。邀请与周记带到模板选择。
6. 使用现有双主题和tab资产。卡片最多两档主动作；小屏或大字体采用纵向布局。日历44px列宽、7列水平滚动，保持日期排列。
7. 今日标题和日期在数据读取前即显示。账户数据确认后total为0时，在主要内容区居中显示单个“添加习惯”，直接进入自定义确认页；首次空账户、全部归档及有习惯但今天无安排均采用此状态。有待做或已完成项仍使用列表，不能以done为0或pending为0误判空态。删除空态推荐、口号和模板选择；空态不叠加明日列表。数据未确认前不显示可创建入口，失败可重试，无新增等待时长或路由。
8. 自定义添加、模板确认及编辑的忙时目标输入框常驻主表单，标注选填，不预填额外数值。数值非空时显示“清空”，清空只移除数值和相关错误，输入框保持显示；沿用原校验、草稿、保存和明日生效逻辑。自定义页标题、入口和创建按钮统一为“添加习惯”。
9. 旧 `jiancheng_daka_plan` 入口保留无SDK、无数据库或供应商调用的静态停用回执，代码继续为 `NOT_ENABLED`，仅提示更新后添加习惯。历史 AI 回执及私有限流仍按受信账户和旧 epoch 清理；全局预算与其他账户不受影响，不触发自动数据删除、资源迁移或云端部署。

## Risks / Trade-offs

- 会话草稿退出会丢失 → 页面明确范围并提供复制；不违背云端唯一持久来源。
- 小目标按钮仍需要用户实际执行 → 使用“已做…记下”且说明自报；不用计时完成暗示。
- 分享关闭导致改版只能fixture验证 → 保留开关，明确真实公开读/发送/采用待授权验收。
- 模拟器无法证明键盘、安全区与大字体 → 宽度样式检查加真机验收清单，分别报告。

## Migration Plan

无数据迁移；本地修改可通过git差异逐文件回退。主题产物由原生成脚本生成，旧 plan 停用提示通过build:cloud同步48个本地云文件并核验；这些仅产生本地产物，不授权部署。助手回退需同时恢复页面、服务、路由与调用装配，不恢复模型配置或供应商调用。保留用户原有.claude目录。当前移除证据及边界见docs/audits/2026-10-09-remove-small-goal-assistant/index.md；早期助手截图和已勾选任务作为历史验证记录保留。
