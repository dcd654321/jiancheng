# Design

## Context

见 proposal.md。页面使用原生 WXML/WXSS，主题由参数生成，现有领域命令和云会话已提供云端确认、冲突与未知结果恢复。冻结基准保存在 docs/implementation/2026-10-27-fusion-native/baseline，哈希记录在 baseline-manifest.json。

## Goals / Non-Goals

**Goals:** 五个核心页共享尺寸与双主题；时间线只做表现层投影；今日和详情共用照片控制器及领域命令；使用隔离原生模拟器量测。

**Non-Goals:** 不改服务端、身份、数据库、云接口和领域持久模型；不自动部署或发布；静态示例数据只用于隔离验收。

## Decisions

1. 原型与截图固定为输入，不修改以迁就实现；提取颜色、字体、间距、行高和按钮参数到主题及页面作用域。相对于手工逐页选色，统一生成可避免主题漂移。
2. 时间线由真实任务列表投影，独立置顶、时间排序、完成项可折叠；不改变原始任务和统计语义。相对于领域改序，表现层投影不会影响云协议。
3. 共用照片控制器适配今日与详情任务来源；沿用 mutate 的云确认、PHOTO_REQUIRED 回退和 subscribeConfirmed 核对，避免复制上传及未知结果处理。
4. 保留原生顶部与底栏，其差异已获接受。业务正文按相同逻辑宽度与数据测量；长名称和大字号允许自然增高，不裁剪信息。
5. 其他页面保留流程，通过共用主题、字体、按钮、分组边界统一视觉。现有 journey-refinement、appearance-themes、today-task-card、progress-review 的领域规则继续适用，实心单行按钮和时间行替代旧卡片外观。

## Risks / Trade-offs

- [原生字体与 HTML 字形存在差异] → 颜色与关键几何单独测量，系统字形和原生区域单列。
- [照片约束读取失败或账户变化] → 服务端强制约束继续生效；操作前检查账户、日期、页面版本，迟到响应不覆盖当前输入。
- [窄屏或大字号操作拥挤] → 保持44px热区、窄屏100px操作列，超长内容增高并在必要时改纵排。
- [隔离模拟不能证明生产云行为] → 分别记录自动测试、原生模拟器、真实云、真机和双账户验收。

## Migration Plan

只修改本地客户端与文档，不需要账户或数据迁移。回滚时仅撤回本变更涉及的客户端、生成主题/图标与验证文件，保留用户原有未提交设计资料；不回滚云数据。提交、部署、合并与发布分别等待适用授权。
