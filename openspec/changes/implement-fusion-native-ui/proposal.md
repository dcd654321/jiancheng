# Proposal

## Why

用户已确认A配色与优化后的C时间线融合稿，并明确授权实施原生页面。当前今日页仍使用独立任务卡片和折叠完成组，详情只展示目标摘要，视觉与交互尚未接入已确认稿。

## What Changes

- 五个核心页面按融合稿重构，其他14页统一视觉；保留暖纸白与原生导航/TabBar。
- 今日采用时间线、独立置顶区、开放式摘要及固定操作列，默认展示完成项。
- 详情接入既有打卡/忙时/撤销/当天目标命令，共享照片约束与结果核对流程。
- 冻结原型与五页截图，建立原生截图、关键尺寸和颜色对照验收。
- 保留真实数据、容量、计划生效、统计、公开入口和所有原有功能门控；不新增云资源、协议或迁移，不部署、不发布。

## Capabilities

### New Capabilities

- `fusion-native-ui`: 融合稿的原生页面、共用打卡交互、双主题及还原验收。当前主规范目录为空，本变更明确衔接已有journey-refinement、appearance-themes、today-task-card和progress-review变更中的视觉约定，历史待验收事项不自动完成。

### Modified Capabilities

无主规范能力变更；现有领域和云协议保持不变。

## Impact

影响小程序WXML/WXSS、主题与Tab图标、今日/详情表现层、测试和原生验证工具。服务端、领域持久模型、数据库、账户与既有云函数生成物不在修改范围。新稿的实心主按钮和时间行结构替代旧稿的任务卡片/描边日常记录按钮要求。
