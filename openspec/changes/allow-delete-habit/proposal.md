# Proposal

## Why

习惯详情的“更多操作”目前只有明日起暂停、恢复和归档；这些操作保留习惯与历史记录。用户需要直接删除一个不再保留的习惯，当前领域命令和云 API 尚未提供单项删除，个人数据页的整账户清除不能用于此入口。

## What Changes

- 在“更多操作”的归档下方增加红色“删除习惯”，摘要改为“暂停、归档、删除”。进行中、已暂停、已归档及尚未开始的习惯均可删除。
- 点击后显示一次确认：标题“删除这个习惯？”，内容“将删除「习惯名称」及其全部历史打卡、备注和待生效计划，无法恢复。其他习惯不受影响。已创建的分享仍可访问，请在分享管理中单独撤销。”；按钮“取消 / 删除”。有未保存备注时补充“未保存的备注也会丢弃”。
- 经确认后提交单项云端删除命令；立即生效，仅删除当前受信账户内目标习惯和它的全部记录。保留账户 epoch、其他习惯、其他记录与账户设置。
- 云端确认后清除目标备注草稿、返回“我的习惯”并提示“习惯已删除”；最后一个习惯删除后清单为空，保留“添加习惯”入口。2026-10-10 按用户反馈修正返回目标。
- 删除期间防重复提交，断网不可删除；失败或结果未知时保留核对入口，只有云端确认后显示成功。跨账户、离开页面、重新进入及跨日后，旧确认不得执行删除。
- 目标习惯被置顶时同步清除该置顶引用；继续使用现有账户提醒的发送前重算机制。已创建的公开分享保持独立快照，由现有分享管理撤销。

### Non-Goals

- 批量删除、回收站、撤销删除、账户数据迁移、恢复旧设备数据及历史数据批量清理。
- 修改暂停和归档的明日生效规则，或用整账户清除代替单项删除。
- 云部署、真实账户删除、提交推送、main 合并或发布；用户于 2026-10-10 授权先实施删除功能。

### Acceptance Criteria

1. 更多操作可找到“删除习惯”；取消弹窗后习惯、打卡、备注和草稿均不变。
2. 确认删除后目标习惯及全部记录从当前账户中移除，今日和进度统计同步更新；其他习惯与设置保持原值。
3. 重复点击、超时重试、另一设备修改、跨日及账户切换不会重复删除、误删其他对象或提前宣告成功。
4. 成功后返回“我的习惯”，删除最后一项后可重新添加；重新打开被删除详情时显示无效链接和“返回我的习惯”出口。
5. 删除已置顶习惯不留下置顶引用；提醒只统计仍存在的待做事项；已有公开分享保持现有行为并有明确提示。

## Capabilities

### New Capabilities

- `habit-deletion`: 单项习惯删除入口、不可恢复确认、云端原子删除、账户隔离、并发与未知结果处理、关联引用和页面更新。

### Modified Capabilities

无。当前 `npm run openspec -- list --specs` 返回 `No specs found`；本次建立独立的新增能力规范。

## Impact

- 客户端：`miniprogram/pages/detail/index.js`、`index.wxml`，按需少量样式；沿用 `services/ui.js`、`cloud-session.js`、`workspace-store.js` 与 `note-drafts.js` 的既有机制。
- 领域与协议：`miniprogram/core/habits.js`、`server/protocol.js`、`server/handler.js`；新增 `deleteHabit` 命令，保持已有命令兼容。
- 置顶引用：`server/cloudbase-repository.js` 与偏好校验公共部分，仅在同一账户、同一 epoch 且置顶命中目标时清理；不改变主题或提醒偏好。
- 云资源：复用 `jiancheng_daka_api`、账户集合 `jiancheng_daka_accounts` 和偏好集合 `jiancheng_daka_preferences`；共享环境其他小程序资源不在范围内，无新增依赖或集合。部署需单独授权。
- 验证：领域、API、云会话、页面、仓库事务和相关功能回归；生成云模块后运行常规检查与 OpenSpec 严格校验。微信工具、真机及双账户验收分别记录，尚未执行。
