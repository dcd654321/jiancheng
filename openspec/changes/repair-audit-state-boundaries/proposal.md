# Proposal

## Why

2026-10-09 全量源码与受控回归审查复现了离线晚回执恢复可写状态、旧 epoch 限流缓存阻塞重建账户，以及旁路清理配置缺省时允许创建无法随账户删除清理的偏好/限流数据。当前规则助手移除 AI 的实施也存在页面残留与跨日交接问题。

## What Changes

- 接受合法晚回执的确认数据，同时保留当前离线只读状态，联网恢复后才重新允许修改。
- 私有限流拒绝缓存绑定 owner 与 epoch，全局限流保持现有语义。
- **BREAKING** features 入口要求 `HABIT_SIDECAR_CLEANUP_ENABLED` 和 `HABIT_LIMITS_VERIFIED` 明确为 `true`；缺省或无效配置无数据库访问并返回未开放。核心 API 的显式清理配置、账户身份与权限保持现状。
- 完成既有纯规则助手范围的入口、标题、文案及控件清理，修复跨日输入与旧导航回调，拒绝跨日消费的预览草稿。
- 提交前再次核对表单业务日；同一会话表单重入接续较新草稿，旧页面及旧回执不得覆盖或清除它。
- 创建容量按当前确认状态核验；系统自动选择明天保持干净基线，第五个已确认创建可核对返回而不重复创建。
- 分享预览/采用在导航期间保持锁定，失败后可重试；离线短句开关禁用，模板数量与单位整组换行，加载卡片补齐内边距。
- 补充上述回归、全路由和原生渲染证据。

## Capabilities

### New Capabilities

- `audit-state-boundaries`: 离线回执、账户代次缓存、可清理的私有能力门禁与跨日预览边界。

### Modified Capabilities

无主规范；本轮规则助手遵守 `remove-ai-integration` 的既有要求，门禁显式要求在本修复 delta 中记录。

## Impact

- 代码：cloud-session、plan-assistant、今日/我的/助手/编辑页面、limits、features 入口及生成云模块；不新增资源或依赖。
- 验收：离线晚回执保持只读且不重复写入；重建 epoch 不继承旧拒绝缓存；缺失清理配置的入口无数据库副作用；全部注册页面无 AI 控件或模型请求；规则预览到确认仍需用户保存。
- 验收：跨日旧表单不可发送写入；嵌套表单返回保留最新草稿；容量状态与按钮一致；导航等待期间不能重复采用或创建。
- 非目标：部署、云端环境变量修改、真实账户写入/删除、数据迁移、发布、Git 提交/推送、main 合并、开启分享或提醒。
- 后续部署必须独立确认两函数配置与目标环境；本地测试和受控截图不抵扣真机、双账户及真实云验收。
