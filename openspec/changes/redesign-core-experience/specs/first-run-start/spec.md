# Spec Delta

## ADDED Requirements

### Requirement: 首次进入的价值表达与主路径

系统 SHALL 在无任何习惯的今日页显示：一句讲清产品用途的标题（再忙也能做小、断了能回来）、四个带双档目标的模板卡（每个直接显示平时目标与忙时目标）、"自己填写"次按钮，以及指向计划助手的辅助入口。系统 SHALL 在无习惯时隐藏页头"添加习惯"按钮，避免同屏出现三个创建入口。

#### Scenario: 新用户打开空账号

- **WHEN** 用户首次进入且云端没有任何习惯
- **THEN** 首屏显示价值标题与四个模板卡，模板卡同时显示平时与忙时目标
- **AND** 不存在页头"添加习惯"按钮与重复的第三个创建入口

#### Scenario: 点模板卡创建

- **WHEN** 用户点击任一模板卡
- **THEN** 进入创建页并预填该模板的名称、平时目标、忙时目标与每天执行
- **AND** 创建页说明条明确"已按模板填好，都可以修改"

#### Scenario: 已有习惯的休息日

- **WHEN** 账号已有习惯但今天没有安排
- **THEN** 显示"今天没有安排／休息日不算漏做"与"查看习惯安排"，不显示模板卡

### Requirement: 仪表约束

模板卡数据 SHALL 来自既有模板表（读一会儿 5/2、走路一会儿 10/3、复习一小段 5/2、整理桌面 3/1，单位分钟），不新增模板或数据字段。

#### Scenario: 模板参数透传

- **WHEN** 用户点击"读一会儿"模板卡
- **THEN** 创建页预填名称"读一会儿"、目标 5 分钟、忙时目标 2 分钟，且尚未创建任何习惯
