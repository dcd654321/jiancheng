# Spec Delta

## ADDED Requirements

### Requirement: 术语统一

系统 SHALL 统一用户可见术语：忙时目标相关状态一律使用"忙时"前缀（忙时完成、忙时目标 N 次、忙时的小目标），不再出现"简化"；云端状态页面的标题与入口名称统一为"云端状态"，不再出现"数据同步"；编辑已有习惯时导航栏标题为"编辑习惯"。

#### Scenario: 同一功能同一名称

- **WHEN** 用户从"我的 → 数据与隐私"进入云端状态
- **THEN** 入口、页面标题与导航栏名称一致为"云端状态"

#### Scenario: 编辑页标题

- **WHEN** 打开已有习惯的编辑页
- **THEN** 导航栏标题显示"编辑习惯"

### Requirement: 失败与加载状态

系统 SHALL 在今日页加载时显示轻量骨架（标题、说明与两张卡片轮廓），失败时标题使用"暂时读不到云端记录"并给出"数据没有丢失"的说明与"重新读取"主按钮；其他页面的读取失败标题同步使用"读不到"表述。错误文案 SHALL 包含下一步动作，不把架构约束表述成用户错误。

#### Scenario: 弱网首次进入

- **WHEN** 云端读取进行中
- **THEN** 显示骨架轮廓与"正在读取云端记录"说明，不显示空白或重复数据声明

#### Scenario: 读取失败

- **WHEN** 云端读取失败
- **THEN** 显示"暂时读不到云端记录"、数据未丢失的说明和"重新读取"按钮

### Requirement: 视觉 token 与青柠语义

系统 SHALL 使用统一 token：页面底色 `#F6F8F5`、卡片纯白圆角 16px、文字两级灰色（`#57675E`／`#7C8B81`）、卡片阴影一致；青柠 `#DDF3A4` 只用于忙时目标相关元素（标签、软按钮、部分完成日历格）；用户可见文字不小于 12px；完成标记出现时播放一次轻量进入动画，不阻塞操作。

#### Scenario: 青柠语义唯一

- **WHEN** 遍历所有页面的青柠色元素
- **THEN** 每个元素都与忙时目标语义相关（忙时标签、按忙时目标打卡、部分完成格）

#### Scenario: 完成动画

- **WHEN** 一项任务从未完成变为完成
- **THEN** 完成标记播放一次短促的进入动画，撤销与后续操作不被阻塞
