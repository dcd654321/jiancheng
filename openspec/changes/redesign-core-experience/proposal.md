# Proposal

## Why

产品体验审查（`docs/UX-DESIGN-REVIEW-20260930.md`）确认三处核心障碍：首次进入没有价值表达、创建入口三分叉；今日任务卡三行相近信息、忙时一键打卡被开关关闭；完成反馈与术语偏技术（"已保存到云端""数据同步""2026-09-24 至"）。用户已明确要求按报告全部实施。

## What Changes

- 空状态重构：价值标题＋双档模板卡（平时／忙时）＋"自己填写"；无习惯时隐藏页头"添加习惯"；助手降为辅助行。
- 今日任务卡重构：名称＋今天目标＋忙时青柠标签两行结构，「打卡」胶囊与「按忙时目标打卡」软按钮；完成后显示"忙时完成／原目标完成"与"撤销打卡"。
- 启用既有 `completeMinimum` 客户端开关：云协议、reducer 与队列已实现并有测试；服务端核验与真机验收单独列项，未完成前不得声称该快捷入口已可用。
- 回归卡两个动作改为直接产生今天的记录（按原目标打卡／用忙时目标打卡），不再跳转详情；目标为 1 或未设忙时目标时退回"今天少做一点"输入。
- 完成反馈文案：首次"第一次，记下了 · 已同步"、常规"记下了 · 已同步"、回归"接上了 · 已同步"；显示时机沿用既有云端确认条件，不变。
- 进度页：中文日期区间、无安排时隐藏日历脚手架并提供创建入口、指标重排、新增"根据最近记录"的规则建议（新纯规则模块，只用计划／完成次数）。
- 术语统一："忙时目标／忙时完成"（删除用户可见"简化"）、"云端状态"（替代与页面标题不一致的"数据同步"）；失败文案给出下一步；今日页失败标题改为"暂时读不到云端记录"。
- 全局视觉 token：页面底色、卡片、青柠仅用于忙时、统一灰色与字号下限 12px；今日加载骨架；完成标记轻量进入动画。

非目标：不改云端协议、数据库、同步引擎、任务排序、撤销窗口与幂等规则；不做周总结、分享上线、提醒上线、主题换肤、排行榜；不合并 main、不部署。

## Capabilities

### New Capabilities

- `first-run-start`: 首次进入的空状态、模板卡与入口层级。
- `today-task-card`: 今日任务卡结构、打卡与忙时一键打卡、回归卡动作、完成反馈文案。
- `progress-insight`: 进度页信息呈现与规则建议。
- `experience-language`: 术语、失败与加载状态文案、全局视觉 token 与应用范围。

## Impact

客户端页面、样式、`config/cloud.js` 开关、`core/date.js` 与新增 `core/progress-advice.js`、测试更新与新增、本文档与实施记录。不涉及数据库、云函数源码与部署；`npm run check:cloud` 应保持通过。用户已授权按报告实施，部署与真机验收仍单独安排。
