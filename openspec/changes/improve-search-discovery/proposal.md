# Proposal

## Why

当前源码禁止全部页面收录，现有路由以账户私有内容为主，缺少可独立浏览的产品与模板入口。新增公开内容和来源归因，让搜索访客了解用途并进入现有创建、打卡流程。

## What Changes

- 新增原生公开介绍页及阅读、步行、复习、整理四份模板内容，复用现有模板目标和创建确认流程。
- 公开页独立打开且不等待账户读取，配置标题、好友分享封面、站内入口及 sitemap 收录白名单。
- 接收启动与热重入场景值，仅保留公开路由及合法模板键；排除爬虫，建立内存中的来源与转化关联。
- 在本应用现有业务 API 中记录账户就绪后的公开浏览、模板选择及服务端确认的创建、打卡归因，保留幂等、账户 epoch 和删除栅栏。
- 增加自动验证、原生编译及隔离模拟器验证记录。

## Capabilities

### New Capabilities

- `search-discovery`: 公开内容、收录边界、搜索来源和已确认转化的可观察行为。

### Modified Capabilities

无。当前主规范目录无已有能力。

## Impact

涉及本仓库小程序公开页、应用生命周期、监控归因、业务协议与服务端监控写入，以及生成云函数副本。无新增运行依赖、集合或付费资源，不修改共享 monitorApi、认证配置和其他应用。

非目标：微信后台配置、内容发布、实际云部署、Git 提交推送、main 合并及排名保证；不开放用户分享、监督、照片等现有功能门禁。

验收：公开入口在云端不可用时仍可读；四模板进入确认且不自动保存；私有页面仍禁止收录并校验账户；未知输入不回显或入统计；重复/迟到请求不跨账户记录。新访客只浏览公开页时不建立账户，其匿名访问量由微信后台统计；本地内存来源在进入账户流程后关联转化，不创建离线队列。
