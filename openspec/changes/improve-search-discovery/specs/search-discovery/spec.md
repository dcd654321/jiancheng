# Spec Delta

## Purpose

为搜索和分享访客提供可直接浏览的渐成产品介绍与四份官方习惯模板，将公开内容与私人账户记录隔离，并用有限来源字段关联用户明确确认的创建和打卡结果，支持验证获客路径且不增加账户持久缓存或公开私人数据。

## ADDED Requirements

### Requirement: 公开内容独立浏览

系统 SHALL 提供原生公开介绍与阅读、步行、复习、整理四份模板；内容包含实际目标、忙时目标、使用步骤、明确的使用入口，不依赖前置页面或账户读取，不包含私人数据。

#### Scenario: 账户未就绪或云服务失败
- **WHEN** 首次访客通过完整公开页面路径进入且账户读取不可用
- **THEN** 页面仍显示完整静态内容，不发起账户创建或业务记录读取

#### Scenario: 选择官方模板
- **WHEN** 用户选择使用一个合法模板
- **THEN** 系统进入现有模板确认流程，只有用户确认且云端成功才创建习惯，不自动打卡

#### Scenario: 非法模板参数
- **WHEN** 参数缺失、未知、非字符串或带有任意输入文本
- **THEN** 页面安全提示并提供返回概览入口，不将输入写入标题、分享或统计

### Requirement: 收录与分享的公开边界

系统 MUST 仅声明公开介绍和模板路由可收录，私有路由保持禁止收录及身份校验；公开页 SHALL 使用明确标题、固定公开分享路径与本地封面，并通过可发现的原生链接互相连接。

#### Scenario: 搜索页面配置
- **WHEN** 校验页面收录规则
- **THEN** 仅公开介绍及只携带模板键参数的模板页面被允许，账户、习惯详情、照片、监督邀请及用户分享快照均被拒绝

#### Scenario: 分享公开内容
- **WHEN** 用户分享介绍或合法模板页
- **THEN** 分享只包含公开路径与官方内容，不包含账户标识、邀请令牌、原始 query 或个人习惯信息

### Requirement: 来源生命周期与最少字段

系统 SHALL 接收冷启动和热重入来源，只保留受限数值场景、公开落地路由或固定今日首页路由、白名单模板键和随机访问标识；MUST 排除场景 1129 爬虫，不存本机快照、原始 query 或 referrerInfo。

#### Scenario: 冷启动与后台重入
- **WHEN** 同次冷启动连续触发启动及首次显示，或从后台通过新入口重入
- **THEN** 冷启动不重复计数，新重入使用新的来源，不复用上次搜索来源

#### Scenario: 无账户的公开阅读
- **WHEN** 访客只阅读公开内容而没有进入账户操作
- **THEN** 不创建账户或统计持久队列；本次内存来源仅在随后账户就绪时尽力关联，进程终止即丢弃

#### Scenario: 名称搜索进入今日首页
- **WHEN** 搜索结果打开今日首页或默认入口
- **THEN** 账户就绪后记录一次来源进入事件，后续创建和打卡沿用本次来源；其他未知私有路由不收集路径和参数

#### Scenario: 账户切换或删除
- **WHEN** 账户上下文或 epoch 改变、删除进入处理中
- **THEN** 旧来源、待发和迟到回执不得写入新账户或已删除账户

### Requirement: 转化基于服务端确认

系统 MUST 通过受信调用者身份和当前账户 epoch 记录公开浏览与模板选择；创建和打卡归因 SHALL 只附于实际成功的服务端业务结果，且重复操作幂等。遥测失败不得阻塞页面或业务成功。

#### Scenario: 创建失败或请求重试
- **WHEN** 创建失败，或确认成功的同一操作重试
- **THEN** 失败不产生创建转化，重试保留原来源且不重复写入转化

#### Scenario: 旧云函数兼容
- **WHEN** 云端未声明支持搜索归因协议
- **THEN** 客户端继续原有创建与打卡协议，不发送新字段或新统计请求

#### Scenario: 伪造来源或身份
- **WHEN** 请求带有未知来源字段、私人输入或客户端身份
- **THEN** 服务端拒绝非法结构，身份仅来自受信平台上下文
