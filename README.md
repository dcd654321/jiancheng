## 当前产品形态

- 今日：紧凑日期和添加入口，突出待完成任务；已完成分组可展开，撤销作为次要动作；“今天少做一点”只调整当天目标。
- 习惯：创建优先填写名称、目标和哪些天做；星期固定七列，时间和忙时目标等折叠为更多设置。支持次日生效的编辑、暂停、恢复和归档；详情备注与历史按需展开。
- 进度：近7天/28天实际完成次数、计划次数为主，比例为辅助；日历补充文字状态，按日明细和习惯汇总分层。
- 我的：习惯管理、首页短句开关、数据与隐私、使用帮助和微信内置反馈。数据管理二级页集中云端状态及双重确认删除；不再生成设备导出文件。
- 计划助手：根据习惯类型、可用时间和执行日生成本机规则建议，再由用户确认带入表单。当前不是联网AI，不产生模型费用，也不能按“AI生成”宣传。
- 首页短句：每次冷启动随机选择，会话内稳定，可关闭，不联网、不记本机索引。

正式工作区只有云端一种数据来源。应用启动后用微信云函数上下文识别账户，读取云端数据；不要求额外同意云端存储，不提供“本机/云端切换”、手动连接或断开入口。

已确认的响应和当前未确认操作只在运行内存中暂存；不写 `wx` 本机存储或设备文件。已有开发期本机键不主动读取、上传、合并或删除，旧版本若留有未上传记录，需要在切换前单独审计。

## 同步与可靠性

- 云端读取失败时显示“暂时无法读取记录”，不能查看旧快照或打卡；“重新读取”重新请求云端。
- 打卡、撤销、简化、备注、习惯和设置修改均直接请求云函数，收到匹配的云端确认后才更新为“已保存”。
- 响应丢失时当前会话保留同一操作标识供幂等重试；重启后重新拉取云端，不在本机排队。
- 回到前台时按需读取云端；应用可见且网络恢复时最多合并触发一次恢复，不无限循环请求。
- 云状态变化即时通知页面；离线和未确认操作不显示保存成功。
- 未保存备注暂存在本次应用会话内，返回详情仍保留；不会自动提交，结束小程序进程后不保证保留。跨日草稿不能误存到今天，账户/数据代际变化清除旧草稿。
- 多设备版本冲突不会覆盖云端；页面读取新云快照，用户需要重新操作。
- 删除个人数据必须收到云端 `purge` 的有效确认；旧设备键和旧导出文件不被客户端自动清除。删除清理中断后，可凭云端状态在下次读取时继续。
- 删除后云端保留新的数据代际、版本及最小删除回执，用于阻止旧请求恢复已删除数据。隐私说明仍需明确其用途与保留期限。

详细协议与边界见 [docs/CLOUD-SYNC.md](docs/CLOUD-SYNC.md)。
