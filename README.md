## 同步与可靠性

- 首次云端读取失败时显示恢复入口，不伪造空账户；会话内已有本账户确认数据且仅读取失败时保留只读内容。没有本机持久快照，断网不能打卡或修改；“重新读取”请求云端。
- 打卡、撤销、简化、备注、习惯和设置修改均直接请求云函数，收到匹配的云端确认后才更新为“已保存”。
- 响应丢失时当前会话保留同一操作标识供幂等重试；重启后重新拉取云端，不在本机排队。
- 回到前台时按需读取云端；应用可见且网络恢复时最多合并触发一次恢复，不无限循环请求。
- 云状态变化即时通知页面；离线和未确认操作不显示保存成功。
- 未保存备注暂存在本次应用会话内，返回详情仍保留；不会自动提交，结束小程序进程后不保证保留。跨日草稿不能误存到今天，账户/数据代际变化清除旧草稿。
- 多设备版本冲突不会覆盖云端；页面读取新云快照，用户需要重新操作。
- 习惯详情的“更多操作”可删除单个习惯及其全部打卡、备注和待生效计划；确认后立即生效且无法恢复，成功后返回“我的习惯”。删除与目标置顶引用在云端同一事务中提交；已创建的公开分享需在分享管理中单独撤销。实施与本地验证见 [删除功能记录](docs/HABIT-DELETION-20261010.md)，云端产物尚未部署。
- 删除个人数据必须收到云端 `purge` 的有效确认；旧设备键和旧导出文件不被客户端自动清除。删除清理中断后，可凭云端状态在下次读取时继续。
- 删除后云端保留新的数据代际、版本及最小删除回执，用于阻止旧请求恢复已删除数据。隐私说明仍需明确其用途与保留期限。

详细协议与边界见 [docs/CLOUD-SYNC.md](docs/CLOUD-SYNC.md)。
