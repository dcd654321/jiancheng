## 当前产品形态

- 今日：紧凑日期和添加入口，突出待完成任务；已完成分组可展开，撤销作为次要动作；“今天少做一点”只调整当天目标。
- 习惯：创建优先填写名称、目标和哪些天做；星期固定七列，时间和忙时目标等折叠为更多设置。支持次日生效的编辑、暂停、恢复和归档；详情备注与历史按需展开。
- 进度：近7天/28天实际完成次数、计划次数为主，比例为辅助；日历补充文字状态，按日明细和习惯汇总分层。
- 我的：习惯管理、首页短句开关、数据与隐私、使用帮助和微信内置反馈。数据管理二级页集中同步、CSV、导出与找回及双重确认删除。
- 计划助手：根据习惯类型、可用时间和执行日生成本机规则建议，再由用户确认带入表单。当前不是联网AI，不产生模型费用，也不能按“AI生成”宣传。
- 首页短句：首次固定、后续冷启动随机且避免相邻重复；会话内稳定，可关闭，不联网。

正式工作区只有云端一种数据来源。用户首次阅读数据说明并同意后，应用用微信云函数上下文识别账户，读取云端数据；不提供“本机/云端切换”、手动连接或断开入口。

本机只承担两类职责：保存最近一次云端确认快照，供断网时查看；保存尚未确认的当天操作队列，恢复网络后自动重试。已有开发期本机记录不会自动上传、合并或成为正式数据，只能从备份页导出。

## 同步与可靠性

- 首次未同意时不联网，也不会伪造一个可编辑的空账户。
- 无缓存且读取失败时显示“暂时无法读取记录”，不会以空数据覆盖云端。
- 首次读取失败后的“重新读取”会重新发起初始化，不需要再次同意、清缓存或重启。
- 当天打卡、撤销、简化、恢复和备注先持久化到队列并立即投影到界面，再由单一后台任务顺序提交。
- 创建、长期编辑、暂停、恢复、归档和设置要求在线确认；未确认时不提示保存成功。
- 回到前台先处理待同步操作；距离上次网络尝试不足30秒时不重复轮询。
- 应用可见且网络恢复时合并触发一次同步；300ms去抖、自动恢复启动间隔至少1.5秒，不定时循环请求，冲突时停止。
- 同步变化即时通知当前页面；首页仅在离线、待同步或失败时显示入口，离线不会误报“数据已同步”。
- 未保存备注暂存在本次应用会话内，返回详情仍保留；不会自动提交，结束小程序进程后不保证保留。跨日草稿不能误存到今天，账户/数据代际变化清除旧草稿。
- 多设备版本冲突会停止自动上传并保留本机意图，由用户在“数据同步”页明确处理，不自动覆盖或合并。
- 删除个人数据必须收到云端 `purge` 的有效确认，之后才清理本机同步快照、旧开发记录和导出文件；失败时全部保留。
- 删除后云端保留新的数据代际、版本及最小删除回执，用于阻止离线旧设备把已删除数据重新上传。隐私说明仍需明确其用途与保留期限。

详细协议与边界见 [docs/CLOUD-SYNC.md](docs/CLOUD-SYNC.md)。
