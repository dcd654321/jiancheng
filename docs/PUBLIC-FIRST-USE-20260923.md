# 面向普通用户的首次使用优化

日期：2026-09-23。分支：`dev`。

## 判断依据

当前代码已有云端记录、今日打卡、近 7/28 天进度、本机规则计划助手和阅读／复习／整理快捷模板。新用户第一次看到的是数据同意页，原有文案只说“一小步”，没有在同意前说明具体能做什么。空状态已有模板，但未覆盖常见的轻运动场景。“忙时小目标”是产品现有差异点，入口却没有解释它。

## 本次改动

- 首次页面先讲清“平时目标＋忙时小目标＋完成记录”的用途，同时保留云端数据说明与同意入口。
- 空状态明确说明快捷模板在创建前仍可修改，并加入“走路 10 分钟”模板（忙时 3 分钟）。
- 创建表单在模板来源提示中说明已填忙时小目标。没有新增账号、模型调用、后台任务或用户数据字段。

## 面向所有人的后续顺序

1. 接通并验证共享正式云环境，完成双用户隔离、真机和隐私审核；当前测试云不能代表公开可用。
2. 请少量非开发者从首次打开走到第一次打卡，记录他们在哪一步停下、是否理解“忙时小目标”。若多数人仍不理解，再调整引导，不先堆功能。
3. 正式可用后，考虑自愿分享一个不含个人记录的通用入口，让朋友也能从模板开始。分享不以积分诱导，不宣称转发后一定获得奖励；朋友圈展示需单独做平台与真机验证。
4. 观察第一天是否创建并打卡、七天后是否仍主动回来，再决定是否值得做提醒或 AI 计划。统计口径与隐私告知先确定，再加采集。
