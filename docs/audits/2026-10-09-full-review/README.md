## 证据边界与部署注意

- 当前模拟器逻辑窗口 390×671，字号 16，SDK 3.17.3；14 页薄雾绿及 7 个主要页暖纸白，共 40 张保存截图均已查看。320px 本轮未完成设备切换：Windows UI 辅助进程初始化两次均失败，不能以历史截图抵扣。
- 所有账户、状态和写入回执来自 RAM 夹具；延迟 10 秒为人为设置。真实业务写入、分享创建、订阅授权、模型请求均未执行。结束时 `fixturePresentAfterRestore=false`。恢复原服务后的正常读取不计入受控流程结论。
- 模拟测试不证明真机中文键盘、真实弱网、两账户隔离或线上清理。分享与提醒当前关闭，截图只证明关闭态；此次未开启它们。
- 后续部署 features 前必须独立核对本项目 API/features 的 `HABIT_SIDECAR_CLEANUP_ENABLED` 与 `HABIT_LIMITS_VERIFIED`。这两项缺省或无效时新 features 产物会明确返回 NOT_ENABLED；此次未读取或修改线上配置，也未部署。
- 本轮检查通过后，在已覆盖的源码、合同测试和受控路径中未发现尚未修复的问题；以上未验证环境仍需对应验收。
