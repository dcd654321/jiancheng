selected-date-mist/paper观测需planned=5、tasks=5、日期匹配选择；04→05观测分别done=1→0，原领域生成的撤销状态保留今日调小值。工具写操作仅是实际页面处理器收到受控回执，不能证明云事务、重试或账户隔离。337自动回归覆盖相应本地合同。

操作方式：记录、撤销、展开、表单提交和汇总进入详情使用自动化实际tap；7/28天切换与选择日期通过callMethod调用页面处理器。后两项验证渲染与数据结果，未验证点击区域或人工操作体验。以上均为设计检查与自动回归，真实用户验证未执行。

两主题仅配色变化；不存在新主题保存。原生配色采用与客户端相同token及已有素材，工具截图不抵扣真机胶囊/底部安全区与系统键盘验收。没有模拟改变systemInfo来冒充320px布局；本轮未测试320/360/430的实际渲染。
