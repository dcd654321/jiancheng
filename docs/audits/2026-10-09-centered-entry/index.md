# 今日居中新增入口（2026-10-09）

打开即显示今日标题和日期，云端数据在页内读取。首次空账户或今日无任何打卡项时，主要内容区仅显示居中的“添加习惯”，点击直接进入自定义创建页。入口、自定义页标题及创建按钮均使用“添加习惯”。

![当前空状态](01-empty.png)

“没有打卡”按今日没有任何任务处理。有任务但尚未完成、今天全部完成，均保留现有列表。未读取确认前不显示创建入口，读取失败保留重试；没有增加路由或人为等待，没有测量或声称云端请求耗时缩短。

忙时目标输入框默认显示在主表单并标注选填，不需要点展开。留空仍表示不设置；清空只移除数值，输入框保持可见，原校验与保存含义不变。

![添加习惯默认展示忙时目标](02-new-form.png)
