同步时序（详设）

sequenceDiagram
    autonumber
    participant P as 页面
    participant S as sync-engine
    participant C as 云函数 handler
    participant R as repository（事务）
    P->>S: 打卡/撤销/简化/恢复/备注
    S->>S: 乐观投影 + 持久化队列（带 operationId）
    S->>C: mutate(operationId, epoch, expectedRevision, operationDate, command)
    C->>C: 身份校验 / 回执查重 / 版本与代际比较
    C->>R: transact(owner)
    R->>R: 读账户 → reduce 应用命令 → 校验 → revision+1
    R-->>C: 同事务写回 state + receipt
    C-->>S: { ok, snapshot, appliedRevision }
    S->>S: 更新确认快照，清队首

erDiagram

        string owner PK "SHA256(APPID:OPENID)"

        string id PK "客户端稳定ID"
        string createdDate "YYYY-MM-DD"
        int revision "习惯版本"
    }
    VERSION {
        string title "1-20字"
        int target "原目标"
        int minimum "忙时小目标可空"
        string unit "分钟/页/次"
        string weekdays "1-7集合"
        string time "HH:mm可空"
        string effectiveDate "次日生效"
        string status "active/paused/archived"
        int revision "版本号"
    }
    RECORD {
        string id PK "habitId"
        string date PK "YYYY-MM-DD"
