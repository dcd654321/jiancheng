## 视觉与业务差异

- 微信顶部、原生三Tab、系统字形及设备安全区保留。390px原生底部包含34px安全空间；正文测量不把它计为布局误差。
- 原生PNG受开发者工具预览缩放影响；并排图按390逻辑宽归一，2px判断使用SDK返回的逻辑矩形。原始PNG与缩放来源一并保留。
- 暖纸白沿用原主题颜色，共享新版布局；原型只提供薄雾绿稿，暖纸白颜色按主题参数核对。普通Tab图标随secondary、选中图标随primary切换。
- 主标题与习惯名24px，原型返回行标题22px；正文15px、待做任务名16px。待做/完成行最小102/68px，动作列104px、窄屏100px，操作区至少44px，长名称自然增高。
- 原型演示历史、内存保存和预览提示未进入生产逻辑。真实历史、门控入口、照片、监督、提醒、分享、删除确认和公开指南继续保留；功能入口可能使实际页面更长。
- 现有名称20字、备注140字、同时进行5项和长期计划明天生效规则保留。进度仍使用真实领域数据计算7天、滚动30天和月历。

## 复核结论与待验收

视觉复核结论为 **ship**，范围限于390px双主题五页及已列修复；输入宽度、详情字号、计划边界、菜单/开关、进度间距和原生主题恢复均已resolved。320px指定长名、大字、滚动截图未见重叠裁剪。此结论不替代所有状态、真实手机OS、云端或用户验收。

仍待：真实云端照片与目标调整链路、真机软键盘/系统字号、双账户独立验收，以及用户对原生UI与交互的确认。本地验收时未部署、迁移账户、提交、推送、合并或发布；后续 Git 状态以仓库记录为准。

## 复现工具

`qa/fusion-native.cjs`负责隔离准备、刷新和原生截图；`qa/fusion-patch-capture.cjs`记录受影响页面补拍；`qa/fusion-baseline-measure.cjs`只读取冻结HTML；`qa/fusion-compare.cjs`比较逻辑矩形；`qa/fusion-board.cjs`生成并排图；`qa/fusion-source-proof.cjs`与`qa/fusion-evidence.cjs`核对源码、基准和证据。

原生脚本使用预先安装的miniprogram-automator，路径可通过FUSION_AUTOMATOR配置；FUSION_TEMP_ROOT指定独立TEMP目录，FUSION_AUTO_PORT默认9451。浏览器测量与拼图依赖分别通过FUSION_PLAYWRIGHT、FUSION_SHARP指定本机库，不加入小程序运行依赖。先prepare，再由微信工具打开隔离目录和自动化端口；后续源码变化使用refresh，保留隔离启动器。机型通过开发者工具选择，每批宽度断言失败会终止。
