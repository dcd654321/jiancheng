# 渐成习惯打卡：实现基线

2026-09-14品牌名称更新为“渐成习惯打卡”。2026-09-21完成B020评审整改；原型中的旧名称和大口号布局仅作为历史参考，当前页面以任务、计数和表单为主要层级。

参考：`D:/codex/coding/habit-miniapp-redesign/design-core.png`、原型各页面截图，以及同目录 `PRD-V1.0.md`。本工程是原生微信小程序，不是网页包装。

沿用已确认视觉，不新增营销页、图片装饰或内容流。页面按 PRD 进行必要调整：移除积分和三阶段计划；加入星期、简化状态、真实空状态；统计统一近7/28天。

- 颜色：白底 #fff；文字 #183b31；主操作 #245c44；轻反馈 #ddf3a4；分隔线 #e8ede7；次要文字 #65756c。
- 字体：系统中文无衬线。标题22px/700、区块18px/600、正文16px、说明14px；主要按钮至少48px高。日历星期13px、打卡操作说明14px。
- 排版：左右20px，开放列表和细分隔线，无阴影卡片堆叠。普通字段间距20px、紧凑表单16px。星期固定七列、间距4px、按钮48px高；按钮跟随页面滚动，不用悬浮按钮覆盖输入区。
- 导航：原生顶部导航及底部今日/进度/我的；详情使用原生返回栈。
- 图标：原生icon用于完成状态；底部保留六张同风格线性Tab资源。进入/展开箭头复用同一个1.5px线宽SVG并旋转，不新增图标库。
- 首页：紧凑“今日＋日期＋添加习惯”，短句为辅助，随后今日进度、接下来和可展开已完成组。已完成是状态，撤销为次要动作；“今天少做一点”明示目标变化。正式首页不显示“本机模式”或数据源选择。
- 页面：today / progress / mine / edit / detail / manage / data / assistant / sync / restore。编辑复用创建表单；数据管理集中同步、导出、隐私与危险操作；备份页名称为“导出与找回”，不把本机JSON导入云账户。
- 正式状态：三Tab已有同风格线性图标；首次使用先同意数据说明，主数据默认来自云端确认快照；加载、不可用和冲突均使用独立状态，不以空数据代替。

架构：core 纯业务规则 → services 云端主数据、确认快照与持久离线队列 → pages 原生交互；旧本机存储只保留原样导出。业务模块可直接在 Node 测试，无第三方前端运行依赖。采用 JavaScript + JSDoc/CommonJS 以便开发者工具直接导入，暂不引入 TypeScript 编译链。

## B020交互基线

- 创建：名称、目标、哪些天做为主；时间、忙时目标、开始日期折叠为更多设置，已有设置用摘要提示。Unicode名称最多20字；字段就地校验，隐藏字段错误自动展开；异步保存期间禁止修改，失败不丢输入。
- 详情：备注默认入口，已有内容预览、dirty草稿保持展开；编辑独立，暂停/归档收进更多操作；最近28天只列有安排的日期，默认7条可展开。
- 统计：完成次数/计划次数优先，比例其次；日历有完成/计划数字或“休”，补全四类图例；当天明细与习惯汇总分层，统计定义不变。
- 我的：管理、偏好、数据与隐私、帮助反馈；云端删除置于数据二级页危险区域并保留双重确认、云确认后清理及防重锁。
- 计划助手：方向/分钟优先，频率可展开；基础建议可预览并采用到确认表单，不冒称AI、不自动创建、不引入聊天流程。

视觉沿用既有方案而非像素复刻旧原型；以上是用户批准的评审整改。逐页截图、对照清单及尚未完成的真机验证见[UX-FIX-20260920.md](UX-FIX-20260920.md)。
