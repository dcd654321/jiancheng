# 默认云端存储变更记录（2026-09-28）

## 变更范围

已配置的客户端在启动时自动调用现有云账户接口拉取当前微信身份的数据。移除应用自定义的“同意云端存储 / 同意并开始使用”拦截及对应页面分支。本机只保留已确认快照和待同步操作，云端仍是正式数据来源。

首次拉取失败且没有可用缓存时，页面保持不可编辑并显示重试；不会把失败渲染成空账户。已有缓存的离线队列、冲突与命名空间隔离保持原规则。数据与隐私、导出、清除入口未删除；AI 向第三方发送输入前的单次同意及微信提醒订阅授权仍保留。
