版本：V1.0（规划稿）  
日期：2026-09-23  
适用工程：`D:\codex\coding\yidian-miniprogram`

> 本文基于当前源码、产品文档及 2026-09-23 微信开发者工具 363×785 模拟器截图形成。文中“现状”指已有实现；“规划”均为待实施设计，不代表已经开发、部署或通过真机验收。

## 1. 产品结论

“渐成习惯打卡”应占据一个清晰位置：**给总是被忙碌打断的人，用更小的动作把习惯接回来。**

核心承诺：

> 再忙，也能做一点；断了一天，也能轻松回来。

当前产品已经具备完整的个人习惯骨架：创建、执行日、普通目标、忙时小目标、打卡、备注、统计、管理、数据恢复和基础计划建议。最有辨识度的能力是“今天少做一点”，它能把传统打卡产品的成功条件从“完整完成”扩展为“在困难的一天仍保留行动”。

下一阶段的重点是把这个能力从一个次要操作升级为全产品主线，并补上三个决定留存的环节：

1. 首次三分钟内完成第一个真实动作；
2. 到点时能想起，打开后立刻知道做什么；
3. 漏做后没有挫败感，回来时有明确的重新开始入口。

## 2. 市场与竞争判断

2026 年 6 月微信小程序月活约 9.62 亿，生态入口足够大；个人效率工具处在存量竞争中，发布本身不会自动获得流量。公开资料显示，小打卡累计服务上亿用户，证明打卡需求长期存在，但其主要优势来自社群、课程和组织运营。渐成更适合占据“私人、轻量、无排名压力、允许降档”的细分位置。

可服务人群优先级：

| 人群 | 典型问题 | 产品切入点 |
| --- | --- | --- |
| 工作忙、作息波动的上班族 | 计划过满，漏一天后直接放弃 | 普通目标 + 忙时小目标 + 轻松回来 |
| 想恢复阅读、运动、学习的人 | 知道要做，但不知道从多小开始 | 现成模板 + 小目标建议 |
| 对连续天数和排名反感的人 | 打卡产品带来额外压力 | 不惩罚、不公开、不用排行榜 |
| 已经多次失败的习惯用户 | 目标过大，缺少调整机制 | 根据近期完成情况建议缩小目标 |

建议避免继续扩成通用任务管理器。产品只处理“需要反复做的小事”，不承接项目、待办、日程、课程和社群管理。

### 3.2 分步健康度

| 步骤 | 当前表现 | 健康度 | 主要判断 |
| --- | --- | --- | --- |
| 1. 打开“今日” | 今日任务、进度和打卡动作清楚 | 良好 | 任务主次明确；顶部短句与“帮我定个小目标”占用注意力，但没有解释“忙时小目标”的核心价值 |
| 2. 创建习惯 | 默认值完整，保存按钮首屏可见 | 良好 | 七天选择和目标设置易懂；新用户仍需自己判断目标大小，首个成功动作来得偏晚 |
| 3. 查看进度 | 完成次数、计划次数、日历状态齐全 | 良好 | 信息可信；25%记录率容易形成失败感，缺少“你在哪些日子更容易做到”和下一步建议 |
| 4. 使用计划助手 | 阅读、学习、整理、步行四类入口清晰 | 一般 | 表单简单，但与创建页功能重叠；建议结果没有在首屏预演，用户尚不知道它能带来什么 |
| 5. 管理和设置 | 分组规整，数据与隐私入口清楚 | 良好 | 信息架构稳定；“如何想起来用”尚无独立设置和状态说明 |

### 3.3 当前优势

- 今日页只有一个主要任务动作，适合高频快速使用。
- 创建页默认值和模板降低了空白表单压力。
- “忙时的小目标”已进入数据与交互链路，具备形成品牌记忆的基础。
- 统计使用真实完成次数和计划次数，不靠夸张积分制造进步感。
- 数据、同步、导出和删除边界表达清楚，能建立长期记录所需的信任。

### 3.4 主要风险

| 优先级 | 风险 | 影响 |
| --- | --- | --- |
| P0 | 计划时间只排序，不发送提醒 | 用户无法在行动时刻想起产品，留存依赖自己记忆 |
| P0 | 忙时小目标隐藏在“更多设置”和次要操作中 | 最有差异化的能力难被第一次使用者理解 |
| P0 | 漏做后的返回体验与普通打开相同 | 用户容易把一次中断理解为失败 |
| P1 | 进度页强调完成率，缺少可行动解释 | 数字能看见，下一周怎么调不清楚 |
| P1 | 计划助手和创建页职责接近 | 两条创建路径增加选择成本 |
| P2 | 分享和传播出口缺失 | 产品很难通过用户成果自然获得新用户 |

### 3.5 可访问性风险

- 辅助说明、日期、底部导航等文字偏小；需在系统大字号和 320px 宽度下验证可读性与换行。
- 完成状态、日历状态不能只依赖绿色深浅，必须同时保留文字或图形符号。
- 打卡圆形控件、星期按钮和折叠入口需保持至少 44×44px 的有效点击区域。
- 完成后的视觉变化需要同步可读文本，供读屏软件理解“已完成”“小目标完成”“已撤销”。
- 截图无法证明对比度、读屏顺序、焦点、键盘遮挡和真机触摸表现，仍需独立测试。

## 4. 产品亮点设计

### 4.1 亮点一：双档目标

每个习惯包含两个明确档位：

- 平常做：用户理想状态下的完整目标；
- 忙时做：最差的一天也能完成的小动作。

示例：

| 习惯 | 平常做 | 忙时做 |
| --- | --- | --- |
| 阅读 | 20分钟 | 读2页 |
| 步行 | 30分钟 | 下楼走5分钟 |
| 学习 | 完成一节 | 复习5分钟 |
| 整理 | 整理一处 | 收起3件物品 |

首页任务卡同时展示两个动作。默认突出“完成平常目标”，旁边提供“今天做小一点”。用户无需进入详情寻找降档入口。

### 4.2 亮点二：轻松回来

系统不展示“断签”“失败”“归零”。当用户连续若干个计划日没有记录时，首页进入回归状态：

> 今天重新做一点，就算回来。

提供两个动作：

- 按原目标继续；
- 先用忙时小目标回来。

完成后反馈“已经接上了”，统计保留真实历史，不补写未完成记录，也不伪造连续天数。

### 4.3 亮点三：渐成一页

每满 7 个自然日或 7 个计划日生成一张周总结：

- 实际完成次数 / 计划次数；
- 完整目标与小目标各完成几次；
- 最容易完成的星期或时段；
- 下周只给一个调整建议；
- 可选择生成隐私安全的分享卡，默认不含习惯备注、具体时间和账户信息。

示例建议：

> 你在工作日晚上更容易完成。下周继续保持，周三可以直接用小目标。

## 5. 信息架构

底部导航保持三项，不增加新的一级入口：

1. **今日**：行动、回归、完成反馈；
2. **进度**：周总结、日历、单习惯趋势；
3. **我的**：习惯管理、提醒、偏好、数据与隐私。

调整建议：

- “帮我定个小目标”并入创建流程，作为“帮我选一个”入口；
- “提醒设置”进入“我的”的偏好设置，同时每个习惯详情可单独修改；
- 周总结放在进度页顶部，今日页只在新报告生成时显示一次入口。

## 6. 核心流程详细设计

### 6.1 首次使用：三分钟完成第一个动作

#### 目标

用户首次打开后 3 分钟内完成“选择习惯 → 创建 → 第一次打卡”。

#### 页面一：欢迎与数据说明

内容顺序：

1. 标题：“再忙，也能做一点”；
2. 一句话说明双档目标；
3. 云端保存说明；
4. 主按钮：“选一个小目标”。

不展示完整功能清单，不要求先进入“我的”配置。

#### 页面二：模板选择

首屏提供四个真实模板和“自己填写”：阅读、散步、学习、整理。每个模板直接展示双档目标，例如“读5分钟 / 忙时读1页”。

点击模板后进入确认页，名称、普通目标、忙时目标和执行日已经填好。主按钮文案为“从今天开始”。

#### 页面三：第一次完成

创建成功后直接返回今日页并聚焦新任务。任务卡提供：

- “完成5分钟”；
- “今天读1页”。

任一动作完成后显示短反馈：

> 第一次已经记下。明天打开微信，还能从这里接着做。

在首次成功之后再询问提醒或添加到常用入口，避免在用户尚未体验价值前索取权限。

### 6.2 今日页

#### 页面结构

1. 日期与今日状态；
2. 待完成任务；
3. 已完成折叠区；
4. 新增习惯；
5. 新周总结提示（仅有新报告时出现）。

首页短句保留，但仅占一行；当存在回归状态、同步异常或新周总结时，让位给更重要的信息。

#### 任务卡

| 区域 | 内容 |
| --- | --- |
| 主体 | 习惯名称、完整目标 |
| 主动作 | “完成20分钟” |
| 次动作 | “今天做小一点” |
| 辅助 | 备注入口、计划时间、同步状态 |

完成主目标后任务进入已完成区，显示“完整完成”；完成小目标后显示“小目标完成”。两者均计入行动次数，但在统计中分开展示。

#### 异常状态

- 离线：允许当天记录入队，任务卡显示“待同步”；
- 冲突：停止自动覆盖，进入同步页处理；
- 跨日：刷新今日任务，旧页面操作被拒绝并解释；
- 无计划：显示休息日，不制造漏做提示。

### 6.3 创建与编辑

创建页首屏字段：名称、普通目标、忙时目标、哪些天做。时间、开始日期放入更多设置。

调整点：

- 把“忙时小目标”从更多设置移到主表单；
- 名称下方即时给出可执行性提示，例如“把‘多读书’改成‘睡前读5分钟’”；
- 普通目标改变时，给出忙时目标建议，但不自动覆盖用户输入；
- 编辑仍保持次日生效，历史不改写。

### 6.4 提醒与召回

#### 产品原则

- 提醒完全自愿；
- 先体验价值，再请求权限；
- 只在用户选择的时刻提醒；
- 平台权限不足时如实显示状态，不承诺持续推送；
- 拒绝后不在每次打开时重复弹窗。

#### 提醒设置状态

| 状态 | 界面表现 |
| --- | --- |
| 未设置时间 | “设置一个容易做到的时间” |
| 已设时间、未申请通知 | 显示时间；提供“需要时提醒我” |
| 已授权一次或可用额度存在 | 显示“下次提醒已准备” |
| 已拒绝 | 显示“提醒未开启”，可主动重新设置 |
| 平台不可用 | 保留计划时间，仅用于排序并说明原因 |

提醒文案只包含一个动作，例如：“读5分钟，忙的话读1页也算。”点击后直达今日对应任务。

#### 产品内召回

即使没有消息权限，也提供：

- 第三次成功后提示用户添加到“我的小程序”；
- 每周报告生成时在首页展示一次；
- 连续两个计划日无记录时，下次打开进入“轻松回来”状态；
- 首页短句根据状态切换，不随机制造噪音。

### 6.5 完成反馈

反馈持续 1—1.5 秒，不阻塞下一操作：

| 情况 | 文案 |
| --- | --- |
| 第一次完成 | “第一次已经记下。” |
| 完整完成 | “今天这件事，做到了。” |
| 小目标完成 | “忙的时候，做一点也算。” |
| 中断后回来 | “已经接上了。” |
| 当天全部完成 | “今天的安排都记下了。” |

不使用连续天数威胁、倒计时或损失提示。

### 6.6 进度与周总结

进度页默认先回答三个问题：

1. 我最近做了多少次？
2. 哪些日子更容易做到？
3. 下周应该保持还是缩小？

新增“本周一句话”：

- 完成率高且稳定：“当前目标适合你，继续保持。”
- 完整目标少、小目标多：“你一直在行动，可以先保持小目标。”
- 多个计划日未记录：“把目标缩小一档，更容易重新开始。”

建议由透明规则生成，文案标注“根据最近记录”，不包装成 AI。

### 6.7 计划助手

计划助手改为创建页的前置选择器，职责限定为“把模糊愿望改成可执行的小动作”。

输入：方向、最多分钟数、每周可做几天、常见困难。  
输出：习惯名称、完整目标、忙时目标、执行日、一个理由。  
确认：用户必须进入创建确认页后保存；预览不直接创建。

首版继续使用本地规则。未来 AI 仅负责提供候选动作，不能读取历史备注、不能自动修改目标、不能直接创建。

### 6.8 分享卡

周总结页提供“生成一张渐成卡片”，默认内容：

- 本周行动次数；
- 完整完成 / 小目标完成；
- 一句用户可编辑的感受；
- 小程序名称和入口码。

默认隐藏具体习惯名，用户主动勾选后才显示。卡片不设置“邀请多少人解锁补签”等诱导机制。

## 7. 状态与规则

### 7.1 用户阶段

| 阶段 | 判定 | 首要界面 |
| --- | --- | --- |
| 未激活 | 尚无习惯 | 模板选择 |
| 已创建未完成 | 有习惯、无任何记录 | 聚焦第一次完成 |
| 正常使用 | 近7日有记录 | 今日任务 |
| 需要回归 | 连续2个及以上计划日无记录 | 轻松回来 |
| 周期复盘 | 有新的7日统计 | 渐成一页 |

### 7.2 建议规则

- 最近 7 个计划日完整完成率 ≥70%：保持目标；
- 完整完成率 <40%，但小目标完成率 ≥30%：保持小目标一周；
- 总记录率 <30%：建议减少执行日或缩小目标；
- 记录不足 3 个计划日：不输出趋势判断。

所有建议只影响预填值，必须由用户确认。

## 9. 数据指标与实验

### 9.1 核心指标

北极星指标：**每周至少在两个计划日留下真实记录的用户数。**

| 指标 | 定义 | 首期目标值 |
| --- | --- | --- |
| 首次创建率 | 开始使用后创建首个习惯 | ≥65% |
| 首次行动率 | 创建后24小时内至少记录一次 | ≥55% |
| 7日有效留存 | 第7日前后仍有计划日记录 | ≥30% |
| 30日有效留存 | 第30日前后仍有计划日记录 | ≥15% |
| 小目标挽回率 | 选择小目标后完成的次数 / 小目标选择次数 | ≥60% |
| 回归率 | 进入回归状态后7日内再次记录 | ≥25% |

目标值用于验证，不是现有成绩。

### 9.2 首批实验

招募 30—50 名目标用户，连续观察 4 周：

1. 一半用户使用当前创建流程，一半使用模板 + 双档目标流程；
2. 比较首次创建时间、首次行动率和第7日记录率；
3. 访谈漏做后仍回来的用户，确认“轻松回来”是否真正降低压力；
4. 若第7日有效留存低于20%，暂停扩功能，先修首次目标大小和提醒入口。

埋点只记录页面、动作类型、结果和匿名时间，不采集习惯正文、备注或导出内容。

## 10. 实施优先级

### P0：让用户开始并想起来

- 双档目标前置；
- 三分钟首次流程；

### P2：增强但不扩大品类

- 经用户确认的 AI 候选计划；
- 更细的习惯趋势；
- 面向特定场景的模板包。

## 11. 非目标

- 公共动态、排行榜、互相监督社区；
- 金钱押注、补签卡、连续天数惩罚；
- 通用待办、日程和项目管理；
- 自动读取或分析私人备注；
- 未经用户确认自动调整计划；
- 在没有平台授权时承诺持续消息提醒。

## 12. 验收清单

- 新用户能在 3 分钟内完成首次创建和首次记录；
- 忙时小目标在创建页和今日任务卡均可见；
- 完整完成与小目标完成在记录、统计和读屏文本中可区分；
- 漏做后出现回归入口，不出现归零、失败或惩罚文案；
- 提醒请求只由明确的用户点击触发，拒绝后不循环弹出；
- 平台提醒不可用时不影响记录，并显示真实状态；
- 周建议可追溯到规则，记录不足时不强行下结论；
- 分享卡默认不含习惯名、备注和具体时间；
- 320/375/430 宽度、系统大字号、键盘、安全区、iOS 和 Android 真机通过；
- 离线队列、冲突、删除、导出和云端账户隔离保持原有保护。
