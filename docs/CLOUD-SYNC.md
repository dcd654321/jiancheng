## 数据权威与用户入口

正式工作区只有云端一种数据来源。用户不选择“本机模式”或“云模式”，也不手动连接、断开或切换数据源。

首次启动只显示数据说明。用户明确同意后，应用通过微信云函数读取账户；身份来自可信的 APPID、OPENID 和调用来源上下文，客户端不得提交 userId/ownerId。账户键由 APPID 与 OPENID 生成SHA-256摘要，用于隔离和绑定，不是匿名化承诺，也不是登录凭证。

本机保存最近一次云端确认快照及待同步操作，以支持弱网和断网。无确认快照时，远端读取失败必须显示不可用状态，不能生成可编辑空数据。已有开发期本机数据不会自动上传、迁移或合并，只能单独导出。

## 代码分工

- `server/handler.js`：可信身份和来源校验、版本比较、幂等回执、离线日期窗口和删除。
- `server/protocol.js`：动作、字段白名单、请求大小和指纹规范。
- `server/cloudbase-repository.js`：账户状态与操作回执的同事务保存。
- `cloudfunctions/jiancheng_daka_api/index.js`：新部署的微信云函数入口，缺少任一发布开关时返回 `NOT_ENABLED`。
- `miniprogram/config/cloud-resources.js`：业务/AI函数与集合专属名称；构建目录和测试以此核验。
- `miniprogram/services/cloud-binding.js`：按云环境及可选数据命名空间保存一次性同意和云端确认的账户摘要；旧测试默认键保留。
- `miniprogram/services/cloud-transport.js`：仅在配置启用且已同意后调用云函数。
- `miniprogram/services/sync-engine.js`：确认快照、持久队列、投影、串行提交、冲突、恢复副本和删除。
- `miniprogram/services/cloud-session.js`：启动读取、自动提交、30秒前台门槛、在线管理和状态汇总。
- `miniprogram/services/workspace-store.js`：业务页面唯一工作区；旧本机存储只提供导出并在云端删除成功后清理。
- `miniprogram/pages/sync`：数据说明、同步状态、重试、刷新、备份和冲突处理。
- `scripts/build-cloud.cjs`：生成云函数共享代码并检查与服务端源码一致；生成目录不手工修改。

## 协议

`pull` 不带用户身份字段，只读取当前微信账户快照。`mutate` 包含 `operationId`、`epoch`、`expectedRevision`、`operationDate` 和白名单内的 `command`。`purge` 使用相同版本字段，并要求确认值 `DELETE_MY_DATA`。

每次写入都要求账户版本和数据代际匹配。状态和操作回执在同一事务保存；同一操作ID和相同内容重试返回原回执，不重复执行，同一ID换内容会被拒绝。回执淘汰后，旧请求仍受版本比较和数据代际保护。

### 当天记录

完成、撤销、今天简化、恢复目标和备注先同步写入本机队列并投影到界面，再由单一后台任务顺序提交。网络失败保留原操作ID和内容；同时触发多次提交也只运行一个网络任务。服务端允许今天及之前6个自然日内的已有离线记录补同步，并标记为延迟同步；这种自报记录不能作为奖励、积分或实际发生时间证明。

### 计划管理

创建、长期编辑、暂停、恢复、归档、撤销待生效版本和设置修改需要在线确认。客户端先拉取远端版本，再持久化带操作ID的请求并提交；有待同步或冲突时禁止叠加管理操作。超时后保留原请求，用户只能重试，不能重复提交同一意图。日期在请求期间变化时要求重新确认。

### 前台恢复

应用启动读取云端；已有确认快照而网络失败时进入离线可读状态。回到前台先等待或提交待同步队列，队列清空后才考虑刷新；距离上次网络尝试不足30秒不重复轮询。冲突存在时停止自动请求。

B019补充：无确认缓存时，手动`refresh()`复用`start()`重新初始化，避免首次失败后重试入口失效。可见页面订阅会话变化，隐藏/卸载解除订阅；页内输入不因同步通知被清空。离线/错误、待同步、冲突优先于“数据已同步”，同步时间统一显示北京时间。

应用启动只注册一个`onNetworkStatusChange`监听器；网络恢复且应用可见、已同意、配置有效、无冲突时，300ms去抖后尝试恢复，自动恢复启动之间至少间隔1.5秒。隐藏时取消待启动定时器，已在途请求不强行中断；恢复任务等待已有读取/提交结束，再处理原持久队列。没有周期性重试循环，无新网络事件时失败后等待用户重试、下一次前台或网络变化。替换生命周期实例时注销旧监听器。

未点击保存的备注属于会话内草稿，不写设备存储、不调用云端；以账户摘要、数据代际、习惯与日期隔离。切换页面仍保留，进程退出不保证保留；日期变化保留旧文本并禁止错存到今天。点击保存且入队落盘成功后才清除相同草稿，后续新输入不受旧请求确认影响；清除账户数据收到有效云确认后再清理草稿。

## 冲突与失败

- 网络或服务异常：保留快照、队列和操作ID，显示待同步或离线状态。
- 服务端已保存但本机保存确认失败：队首仍保留，后续用同一ID重试。
- 其他设备推进版本或改变数据代际：保存远端快照和本机意图，停止自动上传。
- 慢 `pull` 返回旧版本：不得覆盖期间已落盘的较新写入确认。
- 采用远端：用户必须明确确认 `DISCARD_PENDING`，先保存最近一次本机恢复副本，再替换队列。
- 终止性拒绝、错误账户、缓存损坏或伪造确认：停止写入，不静默丢弃或改为空数据。

当前只提供整批舍弃本机待同步操作，不做逐条合并。恢复副本只保留最近一次，备份可能包含习惯备注，应按私人数据处理。

## 删除与防复活

个人数据删除只能在无待同步队列、无冲突时发起。客户端只接受满足以下条件的云端确认：操作ID一致、应用版本精确递增、返回版本等于应用版本、数据代际已更换、习惯和记录均为空。

确认有效后，先保存新的空云端快照并删除同步恢复副本，再由工作区清理旧开发记录和本机导出文件。网络失败、服务端拒绝或确认字段不匹配时，不清理任何本机数据。

云端清除习惯、记录、设置和旧回执，但保留账户摘要键、递增版本、新数据代际、更新时间及本次删除回执，用于阻止离线旧设备把已删除数据重新上传。删除回执只保存操作ID、请求指纹和版本，不保存原备注。正式隐私说明必须披露最小元数据的用途和保留期限。

云端删除无法远程擦除尚未联网设备上的物理缓存；旧设备重连时依靠数据代际拒绝旧写入，并以新的空快照收敛。
