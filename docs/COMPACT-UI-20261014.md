# 渐成紧凑视觉调整（2026-10-14）

面向日常习惯记录用户，统一字号层级，缩小卡片、表单和设置行的留白。薄雾绿与暖纸白共用相同尺寸。

## 当前尺寸

| 对象 | 调整前 | 调整后 |
| --- | --- | --- |
| 页标题 | 26px | 22px / 600 |
| 分区与任务标题 | 18px | 16px / 600 |
| 正文、表单输入、提交按钮文字 | 16px | 15px |
| 辅助文字 | 14px | 13px |
| 进度主数字 | 42px | 34px |
| 单行提交按钮、输入框、星期选项 | 48px 高 | 44px 高 |
| 双行打卡按钮 | 64px 高 | 52px 最小高度 |
| 设置行 | 56px 最小高度 | 48px 最小高度 |
| 卡片圆角 | 16px | 14px |
| 页边距 | 上20px、左右18px | 上16px、左右16px |

两字文字按钮保留至少44×44px触区。长文字允许换行并撑高组件；大字号下的双档按钮继续纵向排列。日历日期格最小高72px，农历和计数保留12px；字体缩放、键盘出现时提交栏回到内容流、安全区留白沿用现有机制。
