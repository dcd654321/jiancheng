## 2. 关键视觉与交互

![修复后关键状态](audits/2026-10-01-ui-interaction-fixes/fix-overview.png)

图从左到右：完成反馈（F）、错误字段（F）、重读后的主题预览（W）。原始截图及全部分类见[证据说明](audits/2026-10-01-ui-interaction-fixes/README.md)。

核心路径：首次进入→模板/自定义→确认名称与双档目标→明确提交→回今日找到新任务→完成后按原目标或忙时目标记下→等待云确认→已完成分组与可见反馈→需要时撤销或进入详情调整。完成确认前不提前移组或改统计。

使用规则：

- 今日记录按钮沿用50 CSS px高度；辅助撤销维持至少44px点击高度。等待时全部相关任务写按钮禁用，只有当前ID与操作类型显示进行中文案。
- 完成反馈白/纸色表面、1px控件边界、16px圆角，左右16px、底部12px；布局容许最长20字名称换行。今日内容额外预留184px加安全区，列表底部仍可滚到可操作位置。
- 表单错误使用已有语义错误色`#A33D2A`和恢复文字；1px原边框加1px内描边形成2px边界；星期组使用2px内描边。错误不依赖单一颜色判断。
- 主题底栏左右18px，底部16px加`env(safe-area-inset-bottom)`；两个主题使用同一布局，主题页预览留在页面内存。无本机持久账户偏好、快照或离线队列。
- 主题保存冲突先读取当前值并保留预览，用户再次确认才产生新保存。未知结果只核对原请求；账户、epoch或generation变化后旧回调无权更新新上下文。
