# 旧模型建议接口停用说明

2026-10-08：用户授权移除 AI 集成。当前源码只提供固定规则的小目标助手，原模型部署与启用清单停止使用。修改与验证见 [移除记录](REMOVE-AI-INTEGRATION-20261008.md)，实施规范见 [remove-ai-integration](../openspec/changes/remove-ai-integration/proposal.md)。

## 当前代码

- 活动客户端没有模型开关、供应商请求或生成操作；规则预览不发送给第三方，采用后进入可编辑确认页，用户明确保存后仍走主业务云端确认。
- `jiancheng_daka_plan` 的本地产物仅返回 `NOT_ENABLED`，不加载 SDK、不访问数据库或供应商，不预留费用。即使存在旧模型配置也不能开启此版本。
- 主业务函数中的历史 AI 回执及限流记录清理继续保留，沿用受信 owner/epoch 与原清理配置。不要关闭历史删除能力、清空私有集合或迁移数据。

## 云端停用目标与边界

本次没有执行部署或环境变量写入。后续若用户授权云端停用，应先核验旧服务的实际部署环境与调用状态，明确目标为对应共享测试或正式环境的 `jiancheng_daka_plan`，只部署同名停用包，不修改其他应用、认证资源和数据库集合。

旧客户端或在途供应商请求无法通过本地源码变更撤回。云端停用后须独立核验旧请求回执、供应商调用与费用变化。历史模型密钥只在已确认的对应云变量中处理，不输出到日志、聊天或 Git。

## 回滚

恢复本次移除前的明确源码差异，再运行 `npm run build:cloud` 和检查。云端部署回滚与重新启用模型服务须另行授权和核验，不使用历史启用清单直接重开。
