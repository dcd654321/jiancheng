## 用户验收任务

请在微信工具重新编译当前项目后检查：

1. 打开今日，能迅速找到目标任务，理解“做完后再记下”。
2. 选读书模板，改为适合自己的两档值；确认前不创建，非法忙时值能知道如何修正。
3. 按忙时记录一次，再撤销；看到正确名称/实际目标；撤销后的今日目标与原计划关系清楚。
4. 在进度查看两档次数、按习惯事实、展开更多及选日期；能解释记录率分母，知道修改计划明日生效。
5. 切两主题检查长名称和主要动作。真实云写入及主题保存测试需按对应环境单独安排，本轮截图均不代表真实云写成功。

用户测试按设计报告U1–U8记录独立完成、犹豫、误触、回退与求助；人数门槛与候选时长先测基线。当前未组织真实用户测试。
